Go 变量、类型与控制流 ​

前置是能运行一个 Go 模块。第一个程序 说明了如何准备唯一的 main.go。这篇先用几个数值处理一道题：一天目标三次，完成两次时，程序如何算出剩余次数和完成率？

变量、常量与作用域 ​

变量有类型和一块可赋值的位置。var done int 声明后可以立即读取，初值为 0。每种类型有自己的零值，例如布尔值是 false，字符串是空串。若业务要表达“还没统计”和“统计过，结果是零”两种情况，只有一个 int 字段无法区分它们，需要另存状态。

done := 2 让编译器由初始值推定类型。= 给当前名字绑定的位置赋值，短声明则在当前块查找可以复用的名字，同一块至少要引入一个新变量才能使用 :=。进入新的花括号块后，同名变量可以遮蔽外层。比如 done := 2 之后，内部块使用 done := 9，离开块又读到 2；内部若写 done = 9，离开时仍读到 9。这个规则同样适用于 if 的初始化语句。

常量与 iota 枚举 ​

const goal = 3 在编译时确定值。无类型数值常量先按常量规则求值，写入具体类型时检查能否表示。const limit = 256 成立，而 var n byte = limit 无法编译，byte 只能表示 0 至 255。已经存在的运行时整数转成更窄的整数类型时会按转换规则截断，因此外部输入要先验范围。

iota 给出同一组 const 中声明项的序号，第一项为 0。比如 draft = iota、fixed = 100、done = iota 依次声明，就得到 0、100、2。接下来省略表达式的 archived 重复上一项的表达式，得到 3。在组首插入一项会改变后续依赖 iota 的值。数据库或协议里已发布的编号应显式固定。

基本类型、转换与运算 ​

选类型取决于数据要经历什么操作。计数用整数，bool 表达真假，string 保存字节序列。int 的宽度依实现为 32 或 64 位；协议明确要求 64 位时选 int64。byte、rune 分别是 uint8、int32 的别名。近似小数常用 float64，精确到分的金额可以用整数配合单位。Go 还提供 complex64 和 complex128 处理复数。

运算先看操作数类型。两个整数相除向零截断，2/3 为 0，-7/3 为 -2，-7%3 为 -1。先算 float64(done/goal) 会把已截断的结果转成浮点数。要保留比例，先把操作数转成浮点数再除。位操作 &、|、^、&^ 与移位 <<、>> 用于按位处理整数。i++ 是单独的语句。

条件、循环与分支 ​

if 要求布尔条件。&& 从左到右求值，左侧为假时右侧不会执行，|| 在左侧为真时停止。将 total != 0 放在除法左侧，可以在输入为零时跳过除法。switch 从上到下选择第一个匹配的分支，普通分支执行到末尾就结束；没有表达式的 switch 可按条件判断。

for i := 0; i < n; i++ 先初始化，每轮在执行循环体前检查条件，循环体执行完再递增。只依赖条件时可写 for remaining > 0。continue 跳到下一轮，break 退出最近的循环、switch 或 select。跨多层退出时可以给目标语句加标签。return 结束整个函数。

下面让同一份数据分别参与计数和比例计算。先预测把 goal 改为 0 时会进入哪个分支。

go
package main

import "fmt"

func main() {
	goal := 3
	var done int
	for i := 0; i < 2; i++ {
		done++
	}
	switch {
	case goal <= 0:
		fmt.Println("未设置目标")
	case done >= goal:
		fmt.Println("完成")
	default:
		fmt.Printf("还差 %d 次，完成率 %.0f%%\n", goal-done, 100*float64(done)/float64(goal))
	}
}

预期输出

text
还差 1 次，完成率 67%

练习与自检 ​

把 goal 依次设为 0、2、4。给 default 分支改用 float64(done/goal)，哪次能够直接看出区别？

参考解法

三个目标依次得到“未设置目标”“完成”“还差 2 次，完成率 50%”。改为先做整数除法后，第三次的完成率变为 0%。前两个分支都不会求值除法表达式。
