Go gRPC 实践：协议生成、调用边界与调试 ​

前置：Protobuf 的字段和服务、Go Modules与context 取消。本例使用一元 RPC，一次请求对应一次响应。example.com/hello 模块包含协议、生成件、服务注册、客户端以及真实本地 TCP 测试；所有命令从仓库 examples/go/grpc-greeter 执行。

工具、运行库与生成件 ​

protoc 解析协议；protoc-gen-go 生成消息及描述符；protoc-gen-go-grpc 生成客户端桩、服务端接口和注册代码。运行库属于应用依赖，生成插件属于维护依赖。项目固定 grpc-go v1.79.3、protobuf-go v1.36.11；随示例提供的两个生成文件头记录 protoc v7.35.1、protoc-gen-go v1.36.11、protoc-gen-go-grpc v1.6.2。只运行服务与测试可直接使用这些生成件。修改协议再安装对应插件，确保二进制所在目录在 PATH 中。

sh
go install google.golang.org/protobuf/cmd/protoc-gen-go@v1.36.11
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@v1.6.2
protoc -I . --go_out=. --go_opt=paths=source_relative --go-grpc_out=. --go-grpc_opt=paths=source_relative api/hello.proto

协议如何变成 Go 调用 ​

package hello.v1 标识协议的命名空间。option go_package 决定 Go 导入路径和包名。-I . 是 proto 查找根，paths=source_relative 让输出位于协议旁的 api 目录。若编译器找不到一个 .proto，应先定位导入根；若 Go 无法导入生成包，应对照 go.mod、go_package 和实际输出位置。手改生成文件会在下一次生成时丢失。

proto
syntax = "proto3";
package hello.v1;
option go_package = "example.com/hello/api;hellopb";

message HelloRequest {
  string name = 1;
  optional int32 age = 2;
  repeated string tags = 3;
}
message HelloReply { string message = 1; }
service Greeter {
  rpc SayHello(HelloRequest) returns (HelloReply);
}

协议沿用 Protobuf 课的可选 age 和重复 tags。此方法的合同只依赖 name；即使服务保留这些协议字段，当前实现也不据此拒绝请求。

gRPC 一元调用：注册与截止时间 ​

服务端先在 listener 上取得地址，用 RegisterGreeterServer 将生成的方法名与实现绑定，再调用 Serve。客户端复用一个 grpc.ClientConn，通过生成的桩发起每个 RPC。创建 ClientConn 可以先于实际建立底层连接，拨号支持和服务可用性应通过一次有期限的请求观察。服务端去除姓名两端空白，空姓名返回 codes.InvalidArgument；客户端通过 status.Code(err) 决定是否应修改输入。正常结果属于返回消息，失败状态在 RPC 错误中传输。

服务实现与注册
go
package greeter

import (
	"context"
	"strings"

	hellopb "example.com/hello/api"
	"google.golang.org/grpc"
	"google.golang.org/grpc/codes"
	"google.golang.org/grpc/status"
)

type service struct {
	hellopb.UnimplementedGreeterServer
}

func (service) SayHello(_ context.Context, req *hellopb.HelloRequest) (*hellopb.HelloReply, error) {
	name := strings.TrimSpace(req.GetName())
	if name == "" {
		return nil, status.Error(codes.InvalidArgument, "name is required")
	}
	return &hellopb.HelloReply{Message: "Hello " + name}, nil
}

func NewServer() *grpc.Server {
	server := grpc.NewServer()
	hellopb.RegisterGreeterServer(server, service{})
	return server
}

go
package main

import (

带三秒期限的一元调用客户端
go
package main

import (
	"context"
	"flag"
	"fmt"
	"os"
	"time"

	hellopb "example.com/hello/api"
	"google.golang.org/grpc"
	"google.golang.org/grpc/credentials/insecure"
	"google.golang.org/grpc/status"
)

func greet(name string) error {
	conn, err := grpc.NewClient("127.0.0.1:50051", grpc.WithTransportCredentials(insecure.NewCredentials()))
	if err != nil {
		return err
	}
	defer conn.Close()
	ctx, cancel := context.WithTimeout(context.Background(), 3*time.Second)
	defer cancel()
	reply, err := hellopb.NewGreeterClient(conn).SayHello(ctx, &hellopb.HelloRequest{Name: name})
	if err != nil {
		return err
	}
	fmt.Println(reply.GetMessage())
	return nil
}

func main() {
	name := flag.String("name", "", "name to greet")
	flag.Parse()
	if err := greet(*name); err != nil {
		result := status.Convert(err)
		fmt.Fprintln(os.Stderr, result.Code(), result.Message())
		os.Exit(1)
	}
}

启动服务后在第二个终端发送请求。三个命令均在模块根执行，服务仅监听 127.0.0.1。第一次客户端调用应打印 Hello Alice；省略 name 会打印 InvalidArgument name is required 并以非零状态退出。

sh
go run ./cmd/server
sh
go run ./cmd/client -name Alice
go run ./cmd/client

gRPC 的截止时间（deadline）是客户端愿意等待到的时刻。context.WithTimeout 把三秒这样的相对时长转换为这次调用的截止时间；子调用若继承更早的父级期限，以更早者为准。连接复用不会让每次调用共用同一个过期 context。客户端期限已到只能说明它未在限时内获得成功响应；有副作用的请求仍可能已经提交，重试应服从幂等约定。断开、服务不可达、业务拒绝是不同阶段，最终观察到的状态也受连接和剩余预算影响。RPC 期限与重试 · gRPC Go 调用

反射与描述符 ​

排查方法列表时，工具可读取服务开放的反射接口，或从 protoc -I . --descriptor_set_out=api.protoset --include_imports api/hello.proto 获得同版本描述符。能列出方法仅说明拿到了结构描述；租户身份、请求权限和服务逻辑要由一次实际调用验证。示例在本机回环使用 insecure 凭据，部署时应按服务身份、TLS 和信任根配置传输。

从协议到响应的验收 ​

go test -count=1 -v ./... 在操作系统分配的回环端口启动服务并用真实生成客户端发起两次 RPC。合法姓名检查消息内容，空姓名要求 InvalidArgument 且没有成功回复。测试结束会关闭连接、停止服务并等待 Serve 退出，运行无需预占命令行演示的 50051 端口。

双端集成测试
go
package greeter

import (
	"context"
	"net"
	"testing"
	"time"

	hellopb "example.com/hello/api"
	"google.golang.org/grpc"
	"google.golang.org/grpc/codes"
	"google.golang.org/grpc/credentials/insecure"
	"google.golang.org/grpc/status"
)

func TestSayHelloOverTCP(t *testing.T) {
	listener, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		t.Fatal(err)
	}
	server := NewServer()
	done := make(chan error, 1)
	go func() { done <- server.Serve(listener) }()
	t.Cleanup(func() {
		server.Stop()
		<-done
	})
	conn, err := grpc.NewClient(listener.Addr().String(), grpc.WithTransportCredentials(insecure.NewCredentials()))
	if err != nil {
		t.Fatal(err)
	}
	t.Cleanup(func() { conn.Close() })
	client := hellopb.NewGreeterClient(conn)
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()

	reply, err := client.SayHello(ctx, &hellopb.HelloRequest{Name: "Alice"})
	if err != nil || reply.GetMessage() != "Hello Alice" {
		t.Fatalf("valid name: reply=%v, err=%v", reply, err)
	}
	reply, err = client.SayHello(ctx, &hellopb.HelloRequest{})
	if reply != nil || status.Code(err) != codes.InvalidArgument {
		t.Fatalf("missing name: reply=%v, err=%v", reply, err)
	}
}
