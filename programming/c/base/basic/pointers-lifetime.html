C 指针、数组与对象生存期 ​

一个查找函数收到数组后，怎样知道可以读几个元素？找到目标后，能把元素的地址交给调用者吗？先用变量、循环与函数中的成绩数组回答这两个问题。

从对象取得地址 ​

声明 int score = 60; 会创建一个整数对象。&score 产生指向它的指针，int *p = &score; 把这个指针存入另一个对象。*p 访问同一个整数，因此通过 *p = 61; 改写之后，从 score 也能读到 61。复制指针只增加一条访问路径。原对象的大小、生存期和释放责任都没有改变。

const int *p 允许重新指向别的整数，只能通过 p 读取。原对象若可写，其他路径仍能改写它。int *const p 则固定指针本身，仍可通过它改写可写的整数。读一个函数声明时，可以先圈出“允许用哪条路径写入”，再问数据由谁保管。

把数组的边界交给函数 ​

在声明 int scores[] = {59, 60, 80}; 的作用域里，sizeof scores / sizeof scores[0] 等于 3。把 scores 传给函数时，数组表达式通常转换为指向首元素的指针。形参写作 const int values[] 或 const int *values 都无法从这个指针还原调用者数组的长度。另传一个 size_t 表示元素个数，并说明允许哪些输入。

数组下标 values[i] 等价于 *(values + i)。指针加一前进一个元素。对有三个元素的数组，scores + 3 可以作为结束位置，读写时下标只能是 0、1、2。即使两个数组碰巧在内存里相邻，也不能把它们当成同一个数组来计算距离。计数为零时可以在尝试取地址或解引用前结束。

实验：借回第一个达标成绩 ​

保存为 find_score.c。调用约定是，非空输入必须提供连续、有效的 length 个整数。空输入可以传 NULL, 0。成功返回原数组中第一个达标元素的只读地址，没有达标成绩时返回 NULL。

c
#include <assert.h>
#include <stddef.h>

static const int *first_passing(const int *scores, size_t length)
{
    for (size_t i = 0; i < length; ++i) {
        if (scores[i] >= 60) {
            return &scores[i];
        }
    }
    return NULL;
}

int main(void)
{
    int scores[] = {59, 60, 80};
    const size_t count = sizeof scores / sizeof scores[0];
    const int *hit = first_passing(scores, count);
    assert(hit == &scores[1]);
    scores[1] = 72;
    assert(*hit == 72);
    assert(first_passing(scores, 1) == NULL);
    assert(first_passing(NULL, 0) == NULL);
    return 0;
}

用 cc -std=c11 -Wall -Wextra -Werror find_score.c -o find_score 编译，再运行 ./find_score。四个断言通过时程序退出 0，终端没有输出。保留断言检查，编译时不要定义 NDEBUG。第二个断言观察到 72，说明调用方仍拥有数据，返回值与原数组中的元素共享存储。

判断借用何时结束 ​

这里的 scores 在 main 的块中存活，因此返回的地址在这些断言里有效。如果函数在自己内部创建局部数组，再把其中一个元素的地址返回，函数退出时该对象的生存期就已结束。堆上的动态对象则从成功分配延续到释放；成功的非零大小 realloc 也会结束旧对象的生存期，之前保存的别名不能继续用，即使数值地址相同。

若调用者只需要记住成绩，检查返回值后把 *hit 复制到自己的 int 即可。若调用者要长期定位该条记录，可以保存相对于原序列的索引，并规定删除、插入或重排记录后索引的含义。如果接口还需要修改成绩，让调用者提供可写数组并清楚说明写入范围。C11 工作草案，第 6.2.4、6.3.2.1、6.5.6 节

自测。 写出 first_passing(scores + 2, 1) 返回哪个地址，再用断言验证。把长度改成 2 违反了“从此处起还有几个元素”的约定；即便当前输入在第一次迭代就返回，也不能把这种调用写进公共接口的测试。下一课把同样的地址与长度约定用于字节缓冲和字符串。
