Rust 首批实践：借用文本、文件汇总与CLI测试 ​

前置：能在终端切换目录并保存UTF-8文件；随后按工具链→语法→所有权→类型→集合→Result学习。Rust不能把所有权推迟到“高级”才讲，因为函数接口从第一批就要区分获取值与借用值。本篇把这些概念连成完整程序，不依赖另一门语言。

环境、版本与首个断言 ​

本轮仅全文审读与静态核对，示例未执行。下文的 Linux/WSL2 实际编译记录属于此前批次，不代表本轮重新验证；本页所有运行命令与输出均供读者未来自行核对。

本批核对日期2026-10-17，官方stable清单为Rust1.99.1。edition采用2024（最低Rust1.85）；edition是源码兼容设置，不是编译器版本。项目无第三方crate。实际编译、运行、测试环境为Linux amd64/WSL2；Windows需要对应平台链接器，按工具链页配置，不能把Linux结果写成Windows已验证。macOS不作为本轮验收条件。

安装后用 rustc --version、cargo --version 确认实际工具链；有rustup时先看项目版本约定，单次命令可用 cargo +stable test。不要因linker报错改业务代码，先安装平台构建工具；本批隔离环境使用官方组件及Zig0.15.2作为C链接器，未改系统PATH。日常机器按官方安装指引配置链接器即可，项目本身不依赖Zig。

在空目录执行 cargo new hello_rust，进入目录，将 src/main.rs 替换为以下完整程序，运行 cargo run --offline。断言失败会非零退出，成功不会打印断言。

rust
fn count_words(text: &str) -> usize { text.split_whitespace().count() }
fn main() {
    let mut text = String::from("learn rust");
    assert_eq!(count_words(&text), 2);
    text.push_str(" today");
    assert_eq!(count_words(&text), 3);
    println!("words={}", count_words(&text));
}

预期输出 words=3。&text 借用，不消费String；读取结束后才修改。cargo test不运行这个main中的断言，必须实际 cargo run。原基础主文的每个独立main也按此方式替换运行，不能拼在同一文件。

完整文本汇总项目 ​

仓库 examples/rust/line-summary。独立练习按下面文件名保存全部文件；Cargo会生成Cargo.lock，CLI项目应保留它。只读输入，不覆盖文件。接口统计：Rust str::lines分行（支持LF/CRLF，末尾一个终止换行不额外增加空行），空白行计入lines；每行trim后非空计入nonempty；trim后Unicode标量值数计入chars。chars不是UTF-8字节数，也不是所有场景下的视觉字形数量。

Cargo.toml
toml
[package]
name = "line-summary"
version = "0.1.0"
edition = "2024"
rust-version = "1.85"

[dependencies]
src/lib.rs（完整计算与单元测试）
rs
#[derive(Debug, PartialEq)]
pub struct Summary { pub lines: usize, pub nonempty: usize, pub chars: usize }

pub fn summarize(text: &str) -> Summary {
    let mut result=Summary {lines:0,nonempty:0,chars:0};
    for line in text.lines() {
        result.lines+=1;
        let trimmed=line.trim();
        if !trimmed.is_empty(){result.nonempty+=1;}
        result.chars+=trimmed.chars().count();
    }
    result
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn empty_and_unicode() {
        assert_eq!(summarize(""),Summary{lines:0,nonempty:0,chars:0});
        assert_eq!(summarize(" Rust \n\n中文\r\n"),Summary{lines:3,nonempty:2,chars:6});
        assert_eq!(summarize("\n"),Summary{lines:1,nonempty:0,chars:0});
    }
}
src/main.rs（完整CLI）
rs
use std::{env,fs,process::ExitCode};

fn main() -> ExitCode {
    let args:Vec<_>=env::args_os().skip(1).collect();
    if args.len()!=1 {eprintln!("usage: line-summary FILE");return ExitCode::from(2);}
    match fs::read_to_string(&args[0]) {
        Ok(text)=>{
            let report=line_summary::summarize(&text);
            println!("lines={} nonempty={} chars={}",report.lines,report.nonempty,report.chars);
            ExitCode::SUCCESS
        }
        Err(error)=>{eprintln!("error: {error}");ExitCode::FAILURE}
    }
}
tests/cli.rs（完整进程测试）
rs
use std::{fs,process::Command};

#[test]
fn reports_unicode_and_rejects_missing_file_and_arguments() {
    let file=std::env::temp_dir().join(format!("line-summary-{}.txt",std::process::id()));
    fs::write(&file," Rust \n\n中文\r\n").unwrap();
    let output=Command::new(env!("CARGO_BIN_EXE_line-summary")).arg(&file).output().unwrap();
    fs::remove_file(&file).unwrap();
    assert!(output.status.success());
    assert_eq!(String::from_utf8(output.stdout).unwrap(),"lines=3 nonempty=2 chars=6\n");
    let missing=Command::new(env!("CARGO_BIN_EXE_line-summary")).arg(&file).output().unwrap();
    assert_eq!(missing.status.code(),Some(1));
    let usage=Command::new(env!("CARGO_BIN_EXE_line-summary")).output().unwrap();
    assert_eq!(usage.status.code(),Some(2));
    let extra=Command::new(env!("CARGO_BIN_EXE_line-summary")).args(["a","b"]).output().unwrap();
    assert_eq!(extra.status.code(),Some(2));
    fs::write(&file,[0xff,0xfe]).unwrap();
    let invalid=Command::new(env!("CARGO_BIN_EXE_line-summary")).arg(&file).output().unwrap();
    fs::remove_file(&file).unwrap();
    assert_eq!(invalid.status.code(),Some(1));
    assert!(invalid.stdout.is_empty());
    assert!(String::from_utf8(invalid.stderr).unwrap().starts_with("error:"));
}

创建UTF-8文件sample.txt，内容如下（第一行首尾有空格，第二行空）：

text
 Rust 

中文

模块目录执行 cargo run --offline -- sample.txt，预期 lines=3 nonempty=2 chars=6。-- 后参数传给程序，而不是Cargo。执行 cargo test --offline，预期单元测试与CLI进程测试通过；cargo build --release --offline生成优化构建。当前测试只覆盖教学输入，并不证明任意文件规模都可处理。

计算函数借用 &str，返回仅包含计数的Summary，不需要把整个文本clone一份。main拥有read_to_string得到的String，在计算结束前保持它存活；结果不借用文本，因此可以离开输入作用域。args_os保留操作系统路径编码，避免强制假设路径参数均为Unicode字符串。文件内容仍要求UTF-8，非UTF-8会走错误分支。

Result、退出码与E0382排错 ​

CLI无参数或参数多于一个返回2并向stderr打印usage；无法读取文件或内容不是UTF-8返回1并向stderr打印error；成功返回0并写stdout。错误消息中的平台路径/系统描述可能不同，只断言稳定前缀和退出码。read_to_string适合本批小文件，会把整个文件放进内存；大文件应改为BufRead逐行，并重新定义字符/行计数边界，不默默沿用全部行为。

所有权反例保存为独立moved.rs（不加入正常项目src），运行 rustc --edition=2024 moved.rs：

rust
fn main() {
    let text = String::from("rust");
    let moved = text;
    println!("{text} {moved}");
}

预期编译非零退出，诊断包含 E0382（使用已移动的值）。修复不是无条件clone：只读调用通常改接收 &str；确实需要两个独立拥有者才clone。不能返回指向函数内临时String的引用；生命周期注解描述关系，不延长存活。若出现E0502，先找共享借用最后一次使用与可变借用是否重叠，再调整操作顺序，见借用章节。

练习与阶段自检 ​

  1. 为只有换行、只有空格、没有末尾换行及中文输入写预测，再跑测试核对。2. 将统计改为同时返回每行长度，说明应返回Vec拥有结果还是借用临时变量。3. 从另一目录用绝对路径调用程序，确认相对输入路径是相对当前工作目录。4. 回答Copy与clone、Option与Result、package/crate/module的区别。
参考解法

空字符串0行；\n一行空行；仅空格一行但0非空、0字符；中文一行、1非空、2Unicode标量值。函数创建的新长度集合应返回Vec，而不是引用局部Vec。输入相对路径相对启动进程的工作目录，与可执行文件所在目录无必然关系。Copy是类型满足的隐式复制语义；clone是显式复制且成本由类型决定；缺失用Option，需要原因用Result。Cargo package由清单描述，crate为编译单元，module组织crate内部路径与可见性。为原基础练习分数等级可用match 0..=59和60..=100并先定义超范围策略，不靠隐式默认成功。
