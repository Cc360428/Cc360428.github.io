Dart 集合：惰性 Iterable、快照与嵌套对象 ​

List 给元素编号，Set 表达唯一成员，Map 则把键映射到值。Iterable 的承诺更小：调用方可以按开发者定义的顺序逐个取元素。一个传入 Iterable<int> 的函数若要求恒定时间按索引访问，或要求两次遍历完全一致，就需要额外约定。

查询在什么时候看到源列表 ​

where 创建记录筛选条件的惰性对象。调用方每取下一个结果时，迭代器才从源中寻找满足条件的元素。toList 则立即消费序列，分配并填充一个列表。两者发生在不同时间，源改变后可以观察到不同结果。

保存为 collections.dart，执行 dart run collections.dart。

dart
void main() {
  final numbers = <int>[1, 2, 3];
  var visited = 0;
  final even = numbers.where((value) {
    visited++;
    return value.isEven;
  });
  if (visited != 0) throw StateError('eager filter');
  final old = even.toList();
  numbers.add(4);
  final recent = even.toList();
  print('$old / $recent / $visited');
}

预期 [2] / [2, 4] / 7。第一次需要检查 3 个源元素，第二次检查 4 个；已物化的 old 保留创建时的内容。把第二次 toList() 换成 even.first，它会在遇到 2 时停止，累计检查数变成 5。若不存在匹配元素，first 会抛 StateError，所以“空结果是否允许”应由调用方明确。

固定绑定与固定内容分别做什么 ​

final numbers 禁止把变量换绑到另一个列表，仍可以 add。toList(growable: false) 固定长度，已有槽位仍可赋新值。List.unmodifiable(source) 生成不可修改的列表，创建之后改变源列表的外层结构不会追溯改变它。若元素本身也是可变对象，两张列表保存的元素仍可能共享。

dart
void main() {
  final source = <List<int>>[[1]];
  final copy = List<List<int>>.unmodifiable(source);
  source.add([2]);
  source.first.add(9);
  print(copy);
}

第二个程序输出 [[1, 9]]。新增的第二行只在 source 中，修改第一行在两端都可见。要发布独立的二维整数快照，可先逐行创建不可修改列表，再收集成不可修改的外层列表。是否值得付出复制成本取决于接口是否需要稳定结果。

练习时给 where 传入有副作用的回调，分别做两次遍历和一次物化后读两遍；回调数会暴露重复计算。实际业务中的筛选宜保持纯计算，尤其在来源只能消费一次或读取有成本时。下一步可比较多次取值和 Stream 的订阅生命周期。Iterable.where · List.unmodifiable
