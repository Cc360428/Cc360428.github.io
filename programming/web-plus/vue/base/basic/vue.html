Vue 首批完整实践：响应式、props/emits与阅读清单 ​

Vue/Vite 构建、模型测试和 Chromium 交互属于原文 2026-10-17 历史记录；本轮未重跑，不能将模型测试等同于组件挂载和事件验收。

前置为HTML/CSS及JavaScript模块、数组和函数，不要求先学React。本批以Vue3 SFC、响应式和props/emits组织；现有环境参考单列旧CLI边界，旧模板不限制当前完整项目。

环境与第一次运行 ​

本批Vue3.5.44、Vite8.3.4、@vitejs/plugin-vue6.0.10、Node24.21.0/npm11.19.0；2026-10-17核对兼容范围，Windows amd64实际构建、Chromium实际操作。项目不需要全局vue-cli、Router、Pinia或UI库。macOS不纳入验收。

进入examples/web-plus/vue，执行npm ci、npm test、npm run build，再npm run preview -- --port 5191，打开127.0.0.1终端地址。仓库含锁文件；独立重建无锁文件时先npm install，不删除原锁规避版本冲突。需要满足工具要求的Node，不能照旧文安装Node10并宣称兼容当前Vite。

首次空清单；添加→标记完成→筛选→删除均改变当前内存状态。刷新回空是本例预期，不冒充持久化；本批不接数据库和业务HTTP服务。用完预览Ctrl+C，构建步骤见前端工程化。

SFC、模板与组件通信 ​

.vue单文件组件把script setup、template和可选style组合，由构建插件转换。createApp挂载根组件；模板不是任意JS语句执行器。{{title}}输出转义文本，不用v-html处理用户标题。列表key用稳定id。

父组件持有数据，子组件通过defineProps声明只读输入，通过defineEmits声明事件；父组件监听并更新自己的状态。不能在子组件中改props来偷偷改变父状态。声明为Array仅是运行时类型提示，不代替任意外部对象的业务校验；当前数据只由已验证模型创建。

ref、computed与更新 ​

ref在脚本里通过.value访问，模板对顶层ref通常自动解包；不要把这条规则推广为任何嵌套结构都自动解包。computed根据依赖推导结果，读者可跳到过滤知识点而无需先学全套状态库。模板将state=...赋回顶层ref，本项目不直接修改子组件props。

本例模型返回新的状态/数组，便于独立测试；Vue本身也能追踪支持范围内的可变更新，不能把不可变更新约定误说成Vue强制规则。直接解构响应式对象的普通属性可能失去原有访问关系，按需求用toRef/toRefs或保持对象访问；computed不应承担请求和写文件等副作用。

v-model关联输入与状态，submit.prevent阻止默认提交。完成数与筛选值用computed表达，避免watch把两份可推导状态来回同步。数据更新后DOM刷新有批次；需要读更新后的DOM时再使用nextTick，而不是任意等待固定毫秒数。

watchEffect、清理与生态 ​

watch明确指定源，watchEffect自动收集同步执行期间读取的响应式依赖；两者都不是给每个派生值再存一份状态的理由。本例watchEffect同步document.title，并注册清理恢复标题。组件卸载和依赖重新执行的资源清理须考虑；异步回调中何时注册清理有API约束，不能在任意await后假定仍可注册当前清理。

Router和Pinia解决额外问题，不是Vue语言基础；旧Vue CLI处于维护路径，新教学使用当前Vite配置。scoped样式改变选择器匹配范围，不等于Shadow DOM，也不是安全隔离。本项目用普通小型样式文件，无需CSS预处理器。

src/model.mjs
javascript
export const initialState=()=>({nextId:1,notes:[]});
export function addNote(state,title){
 const text=title.trim();
 if(!text||Array.from(text).length>80)throw new Error('标题需要1到80个字符');
 if(state.notes.length>=20)throw new Error('最多20条记录');
 return {nextId:state.nextId+1,notes:[...state.notes,{id:state.nextId,title:text,done:false}]};
}
function requireNote(state,id){if(!state.notes.some(n=>n.id===id))throw new Error('记录不存在');}
export function toggleNote(state,id){
 requireNote(state,id);return {...state,notes:state.notes.map(n=>n.id===id?{...n,done:!n.done}:n)};
}
export function removeNote(state,id){requireNote(state,id);return {...state,notes:state.notes.filter(n=>n.id!==id)};}
export function visibleNotes(state,filter){return state.notes.filter(n=>filter==='done'?n.done:filter==='open'?!n.done:true);}
src/App.vue
vue
<script setup>
import {ref,computed,watchEffect} from 'vue';
import {initialState,addNote,toggleNote,removeNote,visibleNotes} from './model.mjs';
import NoteList from './NoteList.vue';
const state=ref(initialState()),title=ref(''),filter=ref('all'),error=ref('');
const visible=computed(()=>visibleNotes(state.value,filter.value));
const done=computed(()=>state.value.notes.filter(note=>note.done).length);
watchEffect(onCleanup=>{
 const previous=document.title;
 document.title=`阅读清单 · ${state.value.notes.length}条`;
 onCleanup(()=>{document.title=previous;});
});
function submit(){
 try {state.value=addNote(state.value,title.value);title.value='';error.value='';}
 catch(problem){error.value=problem.message;}
}
</script>
<template>
 <main>
  <h1>Vue 阅读清单</h1><p>响应式、计算属性与props/emits；刷新会清空本次练习。</p>
  <form @submit.prevent="submit"><label for="title">阅读标题</label>
   <input id="title" v-model="title" required maxlength="160">
   <button type="submit">添加</button></form>
  <p role="status" aria-live="polite">{{error}}</p>
  <label for="filter">显示</label><select id="filter" v-model="filter">
   <option value="all">全部</option><option value="open">未完成</option><option value="done">已完成</option>
  </select>
  <p>共 {{state.notes.length}} 条，已完成 {{done}} 条</p>
  <NoteList :notes="visible" @toggle="id=>state=toggleNote(state,id)" @remove="id=>state=removeNote(state,id)" />
 </main>
</template>

<script setup>
defineProps({notes:{type:Array,required:true}});

  <button type="button" @click="$emit('toggle',note.id)">{{note.done?'标记未完成':'标记完成'}}</button>
  <button type="button" @click="$emit('remove',note.id)">删除</button>
 </li></ul>
</template>

test('添加、稳定ID更新、筛选和删除保持源状态',()=>{

 assert.equal(original.notes.length,0);state=toggleNote(state,2);

test('输入、上限与不存在ID失败，不应用部分修改',()=>{

npm test预期两组通过，覆盖空白/过长/条数、稳定ID、完成筛选/删除及不改原状态。npm run verify再完成生产构建；模型测试不替代实际Vue挂载和事件验证，本批另走生产预览的键盘提交、过滤、删除、转义、刷新与390px。

Property was accessed during render but is not defined先核对setup绑定与拼写；Invalid prop先看传值与声明；更新数据而DOM尚未刷新时确认nextTick时序。找不到.vue模块先查Vite插件和路径，不把安装一个类型声明包当运行时转换。旧项目迁移应保留依赖/测试依据，本批不顺手升级所有历史Vue项目。

练习与参考 ​

  1. 给子组件增加“仅完成”按钮，应由谁持有过滤状态？2. 比较computed和watchEffect在本项目里的职责。3. 把标题输入重置逻辑移到子组件是否更合适？4. 过滤后删除第二条，预测原清单及下一个id。
提示与参考解法

共享过滤状态仍放最近公共父组件，子组件发出意图事件；只有完全局部、不影响其他组件的状态才留在子组件。computed纯推导列表/数量，watchEffect同步外部标题并清理。表单由App持有title与提交规则，成功后由同一拥有者清空，别让列表组件承担无关表单状态。删除按id操作源清单，下一个id不回收；先在模型测，再走DOM事件。
