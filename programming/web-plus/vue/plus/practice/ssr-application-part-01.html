Nuxt课程目录的手写契约约定了什么 ​

Nuxt课程目录的手写契约约定了什么？手写契约先确定三个只读接口：课程列表、课程详情与请求欢迎语；固定fixture使项目无需外部API和凭据。列表成功返回items，详情格式错误或不存在返回404，筛选无效返回400。错误仅承诺状态码，不依赖框架错误体的全部字段。页面统一显示公开消息，不能把API异常原文当产品文案。

这不是生成后的协议，也不是运行证明。没有POST意味着搜索表单只修改URL，不模拟保存。无认证意味着课程都公开，language仅演示请求作用域；未来增加私有课程必须在API实施真实鉴权，不能以页面守卫补上。contract.json在路由实现前手写，静态fixture是有限三条课程，没有分页或持久化承诺。

Nuxt课程目录怎样串起列表筛选和详情页面 ​

Nuxt课程目录怎样串起列表筛选和详情页面？首页表单把q与level提交到URL，列表按计算值请求本地接口；详情NuxtLink指向slug页面，useAsyncData使用包含id的键。列表把加载、错误、空结果分开：只有成功的items=[]才显示没有课程；失败可显式重试，不自动把网络错误变成空列表。

应用外壳负责欢迎语和compact偏好，课程页面负责资源数据。详情使用路径页面key重建，避免切换slug后旧页面错误继续留在新地址；数据key仍体现资源身份。错误页对404和其他故障给出不同公开消息，返回按钮clearError并导航到列表。表单、label、status/alert与focus样式给出基础可访问性结构，但没有声称经过屏幕阅读器或浏览器验收。

Nuxt本地API怎样限制输入和响应数据 ​

Nuxt本地API怎样限制输入和响应数据？本地API只从冻结的公开fixture选择课程，拒绝非字符串筛选、超过40字符的q和未知level；详情先验证slug再查询。请求头只用于生成固定欢迎语，响应不暴露整个header或服务器配置。冻结嵌套lessons避免未来误写共享数据，但冻结并不等于权限系统，真正的保密依然来自输出范围。

模块层只存公开不可变数据；handler里的language和query属于当前event。所有接口加no-store，整体HTML也有相同header，避免示例被误读成安全共享缓存方案。没有调用任意URL，没有写入和重试副作用。移植到真实后端时需要补上数据库、权限与数据校验，而非把fixture包装成假生产服务。文件约定依据见Nuxt server目录。

服务端实现
javascript
import fixture from '../../fixtures/catalog.json'

// Only public immutable fixture data may be shared across requests.
const courses = Object.freeze(fixture.map(course => Object.freeze({
  ...course,
  lessons: Object.freeze([...course.lessons])
})))

export function listCourses(q, level) {
  return courses.filter(course =>
    (level === 'all' || course.level === level) &&
    course.title.toLowerCase().includes(q.toLowerCase()))
}

export function findCourse(id) {
  return courses.find(course => course.id === id)
}
javascript
import { listCourses } from '../../data/catalog.js'

export default defineEventHandler(event => {
  setHeader(event, 'cache-control', 'no-store')
  const query = getQuery(event)
  const q = query.q === undefined ? '' : query.q
  const level = query.level === undefined ? 'all' : query.level
  if (typeof q !== 'string' || q.trim().length > 40 ||
      typeof level !== 'string' || !['all', 'basic', 'advanced'].includes(level)) {
    throw createError({ statusCode: 400, statusMessage: 'Invalid filter' })
  }
  return { items: listCourses(q.trim(), level) }
})
javascript
import { findCourse } from '../../data/catalog.js'

export default defineEventHandler(event => {
  setHeader(event, 'cache-control', 'no-store')
  const id = getRouterParam(event, 'id') || ''
  const course = /^[a-z][a-z0-9-]{0,39}$/.test(id) ? findCourse(id) : undefined
  if (!course) throw createError({ statusCode: 404, statusMessage: 'Course not found' })
  return course
})
