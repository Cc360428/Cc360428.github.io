云资源：发布、排障与恢复练习 ​

资源治理、备份与退役 ​

维护EC2 资源审阅前先保存账户、区域、实例/卷身份与 IAM 角色，恢复后以停止/终止影响、卷保留和备份可恢复性验收。具体配置见配套示例。

核对日期2026-10-17；适用范围：以AWS EC2 2016-11-15 API模型与IAM概念为例，并对照阿里云ECS中文生命周期说明；云控制台与服务特性按2026-10-17核对，不声称跨云接口等价。示例未执行；真实环境仍需验证产品配置、权限、连通与恢复结果。先读起点理解前置，再按章节完成推演。

恢复目标与演练 ​

云资源备份治理先定义最大可接受数据损失RPO和恢复时间RTO，再选择频率、保留期、隔离账户与加密密钥管理。恢复不仅是创建新卷，还需镜像、配置、网络、身份、DNS与应用校验。备份索引里有snapshot字段只是元数据证据，课堂审阅器不能验证它。真实演练需在独立环境恢复并核对应用数据。

费用与标签治理 ​

云资源费用治理不能仅统计running实例：停止的云盘、保留地址、快照、网关和流量仍可能收费。标签应包含owner/environment/expiry并配合预算告警和清单核查；标签不是权限边界，也不能保证资源一定被自动清理。先定位闲置依赖再退役，删除被共享快照/卷可能影响其他工作负载。不要把课堂假地域用于任何报价估算。

退役与回收顺序 ​

云资源退役先确认业务下线、流量切走和备份策略，再解除依赖并终止专用计算，最后按保留期限处理卷、地址和快照。记录资源ID与删除结果，轮询最终状态而不是只相信API接收请求。误终止后的恢复通常从备份创建新实例，重建身份与网络后核对数据，不是再次start旧ID。删除保护是防误操作层，不能当作灾难恢复能力。

本篇练习与参考解答 ​

练习：停止所有VM是否账单归零？

参考解答

不会自动归零。卷、快照、保留地址、网关和流量仍可能收费，退役需核对依赖及保留规则。

拒绝访问、状态异常与不可达定位 ​

本节沿停止/终止影响、卷保留和备份可恢复性定位失败层；先确认账户、区域、实例/卷身份与 IAM 角色，与配套示例逐项对照，再选择最小修复。

AccessDenied的分层定位 ​

云资源AccessDenied先核对当前身份、角色会话、账户、区域与具体动作，再查身份策略、资源策略、组织显式拒绝和权限边界。拥有控制台登录不等于拥有EC2停止权限；能列举实例也不等于允许对它变更。不要临时加AdministratorAccess解决所有错误，应精确记录被拒动作和资源范围，由授权责任人确认最小变更。

状态迟迟不完成 ​

云资源状态卡住时区分pending/stopping等控制面过渡与来宾系统内部服务状态。先核对平台状态检查、事件、配额或容量，再看系统启动、磁盘空间与应用日志；不停重复start/stop可能放大混乱。强制停止可能丢未落盘数据，应先确认恢复方案和影响范围。课堂清单是静态快照，不用它推断平台当前故障。

运行正常但无法访问 ​

云资源访问失败不能只看running；实例running只说明计算生命周期，DNS、路由、安全组、NACL、主机防火墙、监听地址和应用身份都可能阻断。练习：实例running、状态检查正常，数据库仍拒绝连接，是否重装实例？参考解答：先按网络路径和应用监听分层定位，再改最小配置；云网络专题提供双向路径工作表，重装会丢证据且未解决授权问题。

本篇练习与参考解答 ​

练习：AccessDenied是否可以临时给管理员权限解决？

参考解答

不应默认这样做。先核对动作、身份、资源与显式拒绝/权限边界，再由责任人最小授权。

实例终止后的数据恢复复盘 ​

以下演练将EC2 资源审阅的变更、失败证据和恢复验收串起来；先熟悉配套示例中的账户、区域、实例/卷身份与 IAM 角色。演练未执行。

故障场景与影响 ​

实例终止后重新创建成功，但应用数据丢失，原磁盘也找不到。

先记录首次异常时间、受影响对象和最近变更，区分个别对象失败与整条管理链路异常。以下是排查演练，不是已发生事故的实测记录。

按证据定位原因 ​

  1. 核对账户、区域、实例 ID 与磁盘关联，保存终止操作及删除策略记录。
  2. 检查磁盘类型、DeleteOnTermination 或平台等效配置，区分实例存储与独立持久卷。
  3. 确认实际备份或快照的完成状态、时间点、加密密钥与恢复权限；控制台显示有备份条目还不足以证明能恢复。

恢复步骤与验收 ​

先确认磁盘是否被保留或受平台恢复机制保护；否则从已验证备份恢复到新资源，重新绑定网络与身份。不要假定启动旧实例 ID 能找回已删除数据。

验收：从新资源读取已知数据并核对恢复时间点，确认服务身份、网络和权限可用；在退役流程中补入数据删除与独立备份检查。

将触发条件、直接原因、修复动作、恢复证据和后续检查写入同一份复盘，明确每项后续工作的负责人。机制参考：官方说明。

磁盘删除练习 ​

云资源磁盘练习：stop与terminate对root卷一定相同吗？参考解答：不相同，EBS支持实例停止通常保留卷，终止是否删除由DeleteOnTermination等设置决定；实例存储还有不同持久性边界。课堂rootDeleteOnTermination=true所以报告rootDiskAtRisk。真实平台和磁盘类型必须独立核对，不能把本例布尔值当成跨云默认。

IAM授权练习 ​

云资源角色练习：给实例附只读Describe策略就可以完成应用上传对象存储吗？参考解答：不能，策略动作范围只含EC2列举，还需准确的对象存储动作/资源授权与正确角色信任、配置文件关联。应用短期凭据与人操作实例生命周期是不同权限，不能为了方便共用一把管理员密钥。例子策略不是完整角色部署模板。

云原生清单与后续范围 ​

云资源历史CNCF页面仅保留项目列表外链，不包含实例IAM、备份或生命周期知识，继续作为参考而不冒称完整云教程。新课独立提供资源管理合同，云网络与基础设施自动化分别管理路径和声明状态，避免三套目录复制。自动伸缩、跨区域容灾、生产成本报价和真实恢复演练未交付运行证据，不纳入静态通过。

本篇练习与参考解答 ​

练习：实例终止后start旧ID就能恢复数据吗？

参考解答

不能。通常从已验证备份创建新对象并恢复身份、网络与数据，DeleteOnTermination决定哪些盘可能已删除。
