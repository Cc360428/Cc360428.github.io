管理 Btrfs 设备、容量、子卷与校验 ​

Btrfs 总入口之后，按设备、文件系统、子卷与 scrub 查阅；通用入口和子命令示例各自保留。

btrfs（Linux） · 一种基于写时复制（COW）原理的 Linux 文件系统 ​

此命令也有关于其子命令的文件，例如：device。 更多信息：https://btrfs.readthedocs.io/en/latest/btrfs.html。

  • 创建子卷：
bash
sudo btrfs {{[su|subvolume]}} {{[c|create]}} {{指向子卷的路径}}
  • 列出子卷：
bash
sudo btrfs {{[su|subvolume]}} {{[l|list]}} {{指向挂载点的路径}}
  • 显示空间使用情况信息：
bash
sudo btrfs {{[f|filesystem]}} df {{指向挂载点的路径}}
  • 启用配额（quota）：
bash
sudo btrfs {{[qu|quota]}} {{[e|enable]}} {{指向子卷的路径}}
  • 显示配额（quota）：
bash
sudo btrfs {{[qg|qgroup]}} {{[s|show]}} {{指向子卷的路径}}

btrfs device（Linux） · 管理 btrfs 文件系统中的设备 ​

更多信息：https://btrfs.readthedocs.io/en/latest/btrfs-device.html。

  • 将一个或多个设备添加到 btrfs 文件系统中：
bash
sudo btrfs {{[d|device]}} {{[a|add]}} {{指向设备1的路径 指向设备2的路径 ...}} {{指向 btrfs 文件系统的路径}}
  • 从 btrfs 文件系统中删除设备：
bash
sudo btrfs device remove {{设备路径或设备ID}} {{文件系统挂载点}}
  • 显示错误统计：
bash
sudo btrfs {{[d|device]}} {{[st|stats]}} {{指向 btrfs 文件系统的路径}}
  • 扫描所有磁盘并将所有检测到的 btrfs 文件系统通知内核：
bash
sudo btrfs {{[d|device]}} {{[sc|scan]}} {{[-d|--all-devices]}}
  • 显示详细的每个磁盘的空间分配统计信息：
bash
sudo btrfs {{[d|device]}} {{[u|usage]}} {{指向 btrfs 文件系统的路径}}

btrfs filesystem（Linux） · 管理 btrfs 文件系统 ​

更多信息：https://btrfs.readthedocs.io/en/latest/btrfs-filesystem.html。

  • 显示文件系统使用情况（可以选择以 root 身份运行以显示详细信息）：
bash
btrfs filesystem usage {{指向挂载点的路径}}
  • 显示各个设备的使用情况：
bash
sudo btrfs filesystem show {{指向挂载点的路径}}
  • 对 btrfs 文件系统上的单个文件进行碎片整理（避免在运行数据去重的同时运行）：
bash
sudo btrfs filesystem defragment -v {{指向文件的路径}}
  • 递归对目录进行碎片整理（不跨越子卷边界）：
bash
sudo btrfs filesystem defragment -v -r {{指向目录的路径}}
  • 强制将未写入的数据块同步到磁盘：
bash
sudo btrfs filesystem sync {{指向挂载点的路径}}
  • 递归总结目录中文件的磁盘使用情况：
bash
sudo btrfs filesystem du --summarize {{指向目录的路径}}

btrfs subvolume（Linux） · 管理 btrfs 子卷和快照 ​

更多信息：https://btrfs.readthedocs.io/en/latest/btrfs-subvolume.html。

  • 创建一个新的空子卷：
bash
sudo btrfs {{[su|subvolume]}} {{[c|create]}} {{指向新子卷的路径}}
  • 列出指定文件系统中的所有子卷和快照：
bash
sudo btrfs {{[su|subvolume]}} {{[l|list]}} {{指向 btrfs 文件系统的路径}}
  • 删除一个子卷：
bash
sudo btrfs {{[su|subvolume]}} {{[d|delete]}} {{指向子卷的路径}}
  • 创建现有子卷的只读快照：
bash
sudo btrfs {{[su|subvolume]}} {{[sn|snapshot]}} -r {{指向源子卷的路径}} {{指向目标的路径}}
  • 创建现有子卷的读写快照：
bash
sudo btrfs {{[su|subvolume]}} {{[sn|snapshot]}} {{指向源子卷的路径}} {{指向目标的路径}}
  • 显示有关子卷的详细信息：
bash
sudo btrfs {{[su|subvolume]}} {{[sh|show]}} {{指向子卷的路径}}

btrfs scrub（Linux） · 清理 btrfs 文件系统以验证数据完整性 ​

建议每月运行一次 scrub。 更多信息：https://btrfs.readthedocs.io/en/latest/btrfs-scrub.html。

  • 开始 scrub：
bash
sudo btrfs {{[sc|scrub]}} start {{指向挂载点的路径}}
  • 显示正在进行或上次完成的 scrub 的状态：
bash
sudo btrfs {{[sc|scrub]}} status {{指向挂载点的路径}}
  • 取消正在进行的 scrub：
bash
sudo btrfs {{[sc|scrub]}} {{[c|cancel]}} {{指向挂载点的路径}}
  • 恢复先前取消的 scrub：
bash
sudo btrfs {{[sc|scrub]}} {{[r|resume]}} {{指向挂载点的路径}}
  • 开始擦洗，但要等到 scrub 完成后才能退出：
bash
sudo btrfs {{[sc|scrub]}} start -B {{指向挂载点的路径}}
  • 在安静模式下启动 scrub（不打印错误或统计信息）：
bash
sudo btrfs {{[sc|scrub]}} start {{[-q|--quiet]}} {{指向挂载点的路径}}

管理设备、桌面与启动配置 ​

PCI 与串口诊断、蓝牙、Thunderbolt、亮度、桌面入口和引导配置分别操作不同的系统组件。

lspci（Linux） · 列出所有 PCI 设备 ​

更多信息：https://manned.org/lspci。

  • 显示设备的简要列表：
bash
lspci
  • 显示额外信息：
bash
lspci -v
  • 显示处理每个设备的驱动程序和模块：
bash
lspci -k
  • 显示特定设备：
bash
lspci -s {{00:18.3}}
  • 以可读形式转储信息：
bash
lspci -vm

minicom（Linux） · 与设备的串行接口进行通信 ​

另请参阅：picocom, cu, tio。 更多信息：https://manned.org/minicom。

  • 打开给定的串行端口：
bash
sudo minicom {{[-D|--device]}} {{/dev/ttyUSB0}}
  • 以给定的波特率打开给定的串行端口：
bash
sudo minicom {{[-D|--device]}} {{/dev/ttyUSB0}} {{[-b|--baudrate]}} {{115200}}
  • 在与给定串行端口通信前进入配置菜单：
bash
sudo minicom {{[-D|--device]}} {{/dev/ttyUSB0}} {{[-s|--setup]}}

bluetoothctl（Linux） · 从命令行管理蓝牙设备 ​

另请参阅：bluetui。 更多信息：https://manned.org/bluetoothctl。

  • 进入 bluetoothctl 外壳程序：
bash
bluetoothctl
  • 列出设备：
bash
bluetoothctl -- devices
  • 与一个设备配对：
bash
bluetoothctl -- pair {{mac 地址}}
  • 移除一个设备：
bash
bluetoothctl -- remove {{mac 地址}}
  • 连接一个已配对的设备：
bash
bluetoothctl -- connect {{mac 地址}}
  • 断开一个已配对的设备：
bash
bluetoothctl -- disconnect {{mac 地址}}

bluetoothd（Linux） · 管理蓝牙设备的守护进程 ​

更多信息：https://manned.org/bluetoothd。

  • 启动守护进程：
bash
bluetoothd
  • 启动守护进程，日志输出到标准输出：
bash
bluetoothd {{[-n|--nodetach]}}
  • 指定一个配置文件启动守护进程（默认是 /etc/bluetooth/main.conf）：
bash
bluetoothd {{[-f|--configfile]}} {{配置文件}}
  • 启动守护进程并将详细信息输出到标准错误：
bash
bluetoothd {{[-d|--debug]}}
  • 使用来自 bluetoothd 或插件源中特定文件启动守护进程并输出详细信息：
bash
bluetoothd {{[-d|--debug=]}}{{文件一:文件二:...}}

boltctl（Linux） · 控制雷电（thunderbolt）设备 ​

更多信息：https://manned.org/boltctl。

  • 列出已连接并授权的设备：
bash
boltctl
  • 列出已连接的设备，且包含未授权的设备：
bash
boltctl list
  • 临时授权一个设备：
bash
boltctl authorize {{设备uuid}}
  • 授权并记住一个设备：
bash
boltctl enroll {{设备uuid}}
  • 取消一个设备的授权：
bash
boltctl forget {{设备uuid}}
  • 显示一个设备的详细信息：
bash
boltctl info {{设备uuid}}

brightnessctl（Linux） · GNU/Linux 操作系统上用来读取和控制设备亮度的实用工具 ​

更多信息：https://github.com/Hummer12007/brightnessctl#usage。

  • 列出亮度可变的设备：
bash
brightnessctl --list
  • 打印显示器当前亮度：
bash
brightnessctl get
  • 将显示器背光的亮度设置为指定的百分比：
bash
brightnessctl set {{50%}}
  • 按指定的增量增加亮度：
bash
brightnessctl set {{+10%}}
  • 将亮度降低指定的递减量：
bash
brightnessctl set {{10%-}}

dex（Linux） · DesktopEntry Execution 是一个用于生成和执行 Application 类型的 DesktopEntry 文件的程序 ​

更多信息：https://github.com/jceb/dex#dex。

  • 执行自动启动文件夹中的所有程序：
bash
dex {{[-a|--autostart]}}
  • 执行指定文件夹中的所有程序：
bash
dex {{[-a|--autostart]}} {{[-s|--search-paths]}} {{路径/到/目录1}}:{{路径/到/目录2}}:{{路径/到/目录3}}:
  • 执行 GNOME 环境对应的自动启动程序：
bash
dex {{[-a|--autostart]}} {{[-e|--environment]}} {{GNOME}}
  • 预览在常规自动启动中会执行的程序：
bash
dex {{[-a|--autostart]}} {{[-d|--dry-run]}}
  • 预览 DesktopEntry 属性 Name 的值：
bash
dex {{[-p|--property]}} {{Name}} {{路径/到/文件.desktop}}
  • 为当前目录中的程序创建 DesktopEntry：
bash
dex {{[-c|--create]}} {{路径/到/文件.desktop}}
  • 在指定终端中执行单个程序（桌面文件中设置了 Terminal=true）：
bash
dex --term {{终端}} {{路径/到/文件.desktop}}

grub-mkconfig（Linux） · 生成GRUB配置文件 ​

更多信息：https://www.gnu.org/software/grub/manual/grub/grub.html#Invoking-grub_002dmkconfig。

  • 模拟运行并打印配置到标准输出：
bash
sudo grub-mkconfig
  • 生成配置文件：
bash
sudo grub-mkconfig {{[-o|--output]}} {{/boot/grub/grub.cfg}}
  • 打印帮助页面：
bash
grub-mkconfig {{[-h|--help]}}

启停 Apache 配置、保存日志与移到回收站 ​

a2enconf/a2disconf 成对管理 Apache 配置；logsave 保存命令输出，trash 将文件移到回收站。

a2enconf（Linux） · 在基于 Debian 的操作系统上启用 Apache 配置文件 ​

更多信息：https://manned.org/a2enconf。

  • 启用配置文件：
bash
sudo a2enconf {{配置文件}}
  • 不显示信息性消息：
bash
sudo a2enconf {{[-q|--quiet]}} {{配置文件}}

a2disconf（Linux） · 在基于 Debian 的操作系统上禁用 Apache 配置文件 ​

更多信息：https://manned.org/a2disconf。

  • 禁用配置文件：
bash
sudo a2disconf {{配置文件}}
  • 不显示信息性消息：
bash
sudo a2disconf {{[-q|--quiet]}} {{配置文件}}

logsave（Linux） · 将一个命令的输出保存在日志文件中 ​

更多信息：https://manned.org/logsave。

  • 使用指定的参数执行命令并将其输出保存到日志文件中：
bash
logsave {{path/to/logfile}} {{command}}
  • 从标准输入中获取输入并将其保存在日志文件中：
bash
logsave {{logfile}} -
  • 将输出追加到日志文件，而不是替换其当前内容：
bash
logsave -a {{logfile}} {{command}}
  • 显示详细输出：
bash
logsave -v {{logfile}} {{command}}

trash（Linux） · 管理回收站 ​

更多信息：https://github.com/andreafrancia/trash-cli。

  • 将文件移入回收站：
bash
trash {{路径/到/文件}}
  • 列出回收站中的所有文件：
bash
trash-list
  • 以交互方式从回收站恢复文件：
bash
trash-restore
  • 清空回收站：
bash
trash-empty
  • 永久删除回收站中超过 10 天的所有文件：
bash
trash-empty 10
  • 删除回收站中匹配指定 glob 模式的所有文件：
bash
trash-rm "{{*.o}}"
  • 删除具有指定原始位置的所有文件：
bash
trash-rm /{{路径/到/文件或目录}}
