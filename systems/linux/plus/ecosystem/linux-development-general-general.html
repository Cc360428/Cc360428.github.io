Linux：开发、构建与协作 ​

准备解释器、依赖与开发环境 ​

a2dismod（Linux） · 在基于 Debian 的操作系统上禁用 Apache 模块 ​

更多信息：https://manned.org/a2dismod。

  • 禁用模块：
bash
sudo a2dismod {{模块路径}}
  • 不显示信息性消息：
bash
sudo a2dismod {{[-q|--quiet]}} {{模块路径}}

a2dissite（Linux） · 在基于 Debian 的操作系统上禁用 Apache 虚拟主机 ​

更多信息：https://manned.org/a2dissite。

  • 禁用虚拟主机：
bash
sudo a2dissite {{虚拟主机名}}
  • 不显示信息性消息：
bash
sudo a2dissite {{[-q|--quiet]}} {{虚拟主机名}}

a2enmod（Linux） · 在基于 Debian 的操作系统上启用 Apache 模块 ​

更多信息：https://manned.org/a2enmod。

  • 启用模块：
bash
sudo a2enmod {{模块名}}
  • 不显示信息性消息：
bash
sudo a2enmod {{[-q|--quiet]}} {{模块名}}

a2ensite（Linux） · 在基于 Debian 的操作系统上启用 Apache 虚拟主机 ​

更多信息：https://manned.org/a2ensite。

  • 启用虚拟主机：
bash
sudo a2ensite {{虚拟主机名}}
  • 不显示信息性消息：
bash
sudo a2ensite {{[-q|--quiet]}} {{虚拟主机名}}

archlinux-java（Linux） · 提供 Java 环境设置功能的一个帮助脚本 ​

更多信息：https://wiki.archlinux.org/title/Java#Switching_between_JVM。

  • 列出已安装的 Java 环境：
bash
archlinux-java status
  • 返回当前默认 Java 环境的简称：
bash
archlinux-java get
  • 设置默认的 Java 环境：
bash
archlinux-java set {{java环境}}
  • 取消默认的 Java 环境：
bash
archlinux-java unset
  • 自动设置默认的 Java 环境：
bash
archlinux-java fix

modprobe（Linux） · 从 Linux 内核添加或移除模块 ​

另请参阅：kmod。 更多信息：https://manned.org/modprobe。

  • 假装将模块加载到内核中，但实际上不这样做：
bash
modprobe {{[-n|--dry-run]}} {{模块名}}
  • 加载模块到内核：
bash
sudo modprobe {{模块名}}
  • 从内核移除模块：
bash
sudo modprobe {{[-r|--remove]}} {{模块名}}
  • 从内核移除模块及所有依赖它的模块：
bash
sudo modprobe {{[-r|--remove]}} --remove-holders {{模块名}}
  • 显示内核模块的依赖：
bash
sudo modprobe {{[-D|--show-depends]}} {{模块名}}

编译、链接与执行构建任务 ​

as（Linux） · 一个可移植的 GNU 汇编器 ​

主要用于汇编gcc的输出，以供链接器ld使用。 更多信息：https://manned.org/as。

  • 汇编一个文件，输出为 a.out：
bash
as {{路径/到/文件.s}}
  • 汇编文件，并指定输出文件：
bash
as {{路径/到/文件.s}} -o {{路径/到/输出.o}}
  • 通过跳过空格和注释的预处理过程来更快的产生输出文件（只应该用于可信任的编译器的输出）：
bash
as -f {{路径/到/文件.s}}
  • 将给定路径添加到目录列表，来搜索.include 指令指定的文件：
bash
as -I {{目标文件夹}} {{路径/到/文件.s}}

格式化、测试与性能检查 ​

tmt run（Linux） · 执行测试步骤。默认情况下，所有测试步骤都被执行 ​

更多信息：https://tmt.readthedocs.io/en/stable/stories/cli.html#run。

  • 在每一个计划中执行所有测试步骤：
bash
tmt run
  • 仅在发现步骤中显示将要执行的测试：
bash
tmt run discover {{[-v|--verbose]}}
  • 运行所有测试步骤并调整测试环境配置步骤选项：
bash
tmt run {{[-a|--all]}} provision {{[-h|--how]}} {{container}} {{[-i|--image]}} {{fedora:rawhide}}
  • 仅执行选定的计划和测试：
bash
tmt run plan {{[-n|--name]}} {{/plan/name}} test {{[-n|--name]}} {{/test/name}}
  • 在网页浏览器中显示上次运行的结果：
bash
tmt run {{[-l|--last]}} report {{[-h|--how]}} {{html}} {{[-o|--open]}}
  • 在提供的上下文中运行测试：
bash
tmt run {{[-c|--context]}} {{key=value}} {{[-c|--context]}} {{distro=fedora}}
  • 以交互方式运行测试（在测试运行过程中调试测试代码）：
bash
tmt run {{[-a|--all]}} execute {{[-h|--how]}} {{tmt}} --interactive
  • 使用干模式查看接下来将发生的动作，并将输出详实度设置为最高级：
bash
tmt run {{[-n|--dry]}} {{[-vvv|--verbose --verbose --verbose]}}

tmt try（Linux） · 测试及环境快速上手 ​

更多信息：https://tmt.readthedocs.io/en/stable/stories/cli.html#try。

  • 快速尝试默认的测试环境配置方法（当前工作目录中没有测试）：
bash
tmt try
  • 在当前的工作目录中运行一个测试：
bash
cd {{path/to/test}} && tmt try
  • 使用特定的操作系统：
bash
tmt try {{fedora-41}}
  • 选择定制的镜像和测试环境配置方法：
bash
tmt try {{fedora@container}}
  • 根据定制的筛选条件选择测试：
bash
tmt try {{[-t|--test]}} {{feature}}
  • 配置客户机并等待用户输入指令：
bash
tmt try {{[-a|--ask]}}
  • 直接登录到客户机：
bash
tmt try {{[-l|--login]}}
  • 显示帮助：
bash
tmt try --help

定位运行问题与诊断程序 ​

apport-bug（Linux） · 在 Ubuntu 上提交错误报告 ​

更多信息：https://ubuntu.com/project/docs/contributors/debugging/apport/。

  • 报告整个系统的错误：
bash
apport-bug
  • 报告某个软件包的错误：
bash
apport-bug {{包名}}
  • 报告某个可执行文件的错误：
bash
apport-bug {{可执行文件路径}}
  • 报告某个进程的错误：
bash
apport-bug {{pid}}

bpftrace（Linux） · Linux eBPF 的高级跟踪语言 ​

更多信息：https://github.com/bpftrace/bpftrace/blob/master/man/adoc/bpftrace.adoc。

  • 列出所有可用的探针：
bash
sudo bpftrace -l
  • 运行单行程序（例如按程序进行系统调用计数）：
bash
sudo bpftrace -e '{{tracepoint:raw_syscalls:sys_enter { @[comm] = count(); }}}'
  • 从文件运行程序：
bash
sudo bpftrace {{文件}}
  • 通过 PID 跟踪程序：
bash
sudo bpftrace -e '{{tracepoint:raw_syscalls:sys_enter /pid == 123/ { @[comm] = count(); }}}'
  • 进行试运行并以 eBPF 格式显示输出：
bash
sudo bpftrace -d -e '{{单行程序}}'
  • 显示 版本：
bash
bpftrace {{[-V|--version]}}

专用工具与其他操作 ​

arithmetic（Linux） · 提供交互式算术练习 ​

更多信息：https://manned.org/arithmetic。

  • 开始算术测试：
bash
arithmetic
  • 指定一个或多个算术运算符来设计问题：
bash
arithmetic -o {{+|-|x|/}}
  • 指定范围。加法和乘法问题限定 0 到指定范围之间的数字，包含上区间。减法和除法问题限制结果和运算数字必须在 0 到指定范围之间：
bash
arithmetic -r {{7}}

示例整理自 tldr-pages，作者为 tldr-pages team and contributors，遵循 CC BY 4.0。
