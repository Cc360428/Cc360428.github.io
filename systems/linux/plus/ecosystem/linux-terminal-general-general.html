Linux：终端、会话与日常操作 ​

环境、会话与自动执行 ​

at（Linux） · 稍后执行一次性命令 ​

执行结果将通过邮件发送给用户。 更多信息：https://manned.org/at。

  • 启动 atd 守护进程：
bash
systemctl start atd
  • 以交互方式创建命令并在 5 分钟后执行（完成后按 <Ctrl d>）：
bash
at now + 5 minutes
  • 以交互方式创建命令并在特定时间执行：
bash
at {{hh:mm}}
  • 在今天上午 10:00 从标准输入执行命令：
bash
echo "{{command}}" | at 1000
  • 在下周二执行给定文件中的命令：
bash
at -f {{路径/到/文件}} 9:30 PM Tue
  • 列出当前用户的所有排队任务（与 atq 相同）：
bash
at -l
  • 查看指定任务：
bash
at -c {{任务号}}

专用工具与其他操作 ​

abbr（Linux） · 管理 fish shell 的缩写 ​

用户定义的词在输入后会被较长的短语替换。 更多信息：https://fishshell.com/docs/current/cmds/abbr.html。

  • 添加一个新缩写：
bash
abbr {{[-a|--add]}} {{缩写名}} {{命令}} {{命令参数}}
  • 重命名一个已有的缩写：
bash
abbr --rename {{旧缩写名}} {{新缩写名}}
  • 清除一个已有的缩写：
bash
abbr {{[-e|--erase]}} {{缩写名}}
  • 用 SSH 导入另一台主机上定义的缩写：
bash
ssh {{主机名}} abbr {{[-s|--show]}} | source

bitwise（Linux） · 支持动态基数转换和位操作的多基数交互式计算器 ​

更多信息：https://github.com/mellowcandle/bitwise。

  • 使用交互模式运行：
bash
bitwise
  • 从十进制转换：
bash
bitwise {{12345}}
  • 从十六进制转换：
bash
bitwise {{0x563d}}
  • 转换 C 风格的计算：
bash
bitwise "{{0x123 + 0x20 - 30 / 50}}"

cal（Linux） · 打印日历信息，高亮显示当前日期 ​

更多信息：https://manned.org/cal。

  • 显示当前月份的日历：
bash
cal
  • 显示上个月、当前月和下个月：
bash
cal {{[-3|--three]}}
  • 使用星期一作为一周的第一天：
bash
cal {{[-m|--monday]}}
  • 显示特定年份的日历（4位数字）：
bash
cal {{年份}}
  • 显示特定月份和年份的日历：
bash
cal {{月份}} {{年份}}

dmesg（Linux） · 显示或控制内核环形缓冲区 ​

另请参阅：journalctl。 更多信息：https://manned.org/dmesg。

  • 显示来自内核环形缓冲区的所有消息：
bash
sudo dmesg
  • 只显示严重错误级别的消息：
bash
sudo dmesg {{[-l|--level]}} err
  • 等待新消息。仅在具有可读性的系统上支持此功能，类似于 tail -f（从内核 3.5.0 版本开始）：
bash
sudo dmesg {{[-w|--follow]}}
  • 筛选内核日志中的 memory 记录；它不表示当前可用内存：
bash
sudo dmesg | grep {{[-i|--ignore-case]}} memory
  • 以分页方式显示内核缓冲区的所有消息：
bash
sudo dmesg | less
  • 打印人类可读的时间戳（从内核 3.5.0 版本开始）：
bash
sudo dmesg {{[-T|--ctime]}}
  • 启用人类可读的输出：
bash
sudo dmesg {{[-H|--human]}}
  • 着色输出：
bash
sudo dmesg {{[-L|--color]}}

dmidecode（Linux） · 以人类可读的格式显示 DMI（也称为 SMBIOS）表内容 ​

需要 root 权限。 另请参阅：inxi, lshw, hwinfo。 更多信息：https://manned.org/dmidecode。

  • 显示所有 DMI 表内容：
bash
sudo dmidecode
  • 显示 BIOS 版本：
bash
sudo dmidecode {{[-s|--string]}} bios-version
  • 显示系统的序列号：
bash
sudo dmidecode {{[-s|--string]}} system-serial-number
  • 显示 BIOS 信息：
bash
sudo dmidecode {{[-t|--type]}} bios
  • 显示 CPU 信息：
bash
sudo dmidecode {{[-t|--type]}} processor
  • 显示内存信息：
bash
sudo dmidecode {{[-t|--type]}} memory

konsole（Linux） · Konsole: KDE 终端模拟器 ​

更多信息：https://docs.kde.org/stable_kf6/en/konsole/konsole/command-line-options.html。

  • 在特定目录中打开一个新的 Konsole：
bash
konsole --workdir {{path/to/directory}}
  • 运行特定命令，退出窗口后不要关闭窗口：
bash
konsole --noclose -e {{命令}}
  • 打开新标签页：
bash
konsole --new-tab
  • 在后台打开 Konsole 并在按下 <Ctrl Shift F12>（默认）时显示在最前面：
bash
konsole --background-mode
  • 使用紧急备冗配置文件打开 Konsole：
bash
konsole --fallback-profile

line（Linux） · 读取单行输入 ​

更多信息：https://manned.org/line.1。

  • 读取输入：
bash
line

lvs（Linux） · 显示逻辑卷信息 ​

另请参阅：lvm。 更多信息：https://manned.org/lvs。

  • 显示逻辑卷信息：
bash
sudo lvs
  • 显示所有逻辑卷：
bash
sudo lvs {{[-a|--all]}}
  • 改变默认显示以显示更多细节：
bash
sudo lvs {{[-v|--verbose]}}
  • 只显示特定字段：
bash
sudo lvs {{[-o|--options]}} {{字段1,字段2,...}}
  • 将字段附加到显示：
bash
sudo lvs {{[-o|--options]}} +{{字段名}}
  • 抑制标题行：
bash
sudo lvs --noheadings
  • 使用特殊分隔符分隔特定字段：
bash
sudo lvs --separator {{=}}

sleep（Linux） · 延迟指定的一段时间 ​

更多信息：https://www.gnu.org/software/coreutils/manual/html_node/sleep-invocation.html。

  • 按秒数延迟：
bash
sleep {{seconds}}
  • 延迟 [m]分钟（其他元素 [d]天，[h]小时，[s]秒，[inf]无穷 也可以使用）：
bash
sleep {{minutes}}m
  • 延迟 1 [d]天 3 [h]小时：
bash
sleep 1d 3h
  • 在 20 [m]分钟 延迟后执行指定命令：
bash
sleep 20m && {{command}}

timedatectl（Linux） · 控制系统时间和日期 ​

更多信息：https://www.freedesktop.org/software/systemd/man/latest/timedatectl.html。

  • 检查当前系统时钟时间：
bash
timedatectl
  • 直接设置系统时钟的本地时间：
bash
timedatectl set-time "{{yyyy-MM-dd hh:mm:ss}}"
  • 列出可用时区：
bash
timedatectl list-timezones
  • 设置系统时区：
bash
timedatectl set-timezone {{时区}}
  • 启用网络时间协议（NTP）同步：
bash
timedatectl set-ntp on
  • 将硬件时钟时间标准更改为本地时间：
bash
timedatectl set-local-rtc 1

xcowsay（Linux） · 在您的 Linux 桌面上显示一头可爱的牛和指定的消息 ​

牛的显示时间是固定的或则是根据文本大小计算得出的。 点击牛即马上关闭。 更多信息：https://manned.org/xcowsay。

  • 显示一头说 “hello, world” 的牛：
bash
xcowsay "{{hello, world}}"
  • 显示一头牛和消息，该消息是另一个命令的输出：
bash
ls | xcowsay
  • 显示一头有指定 X 和 Y 坐标的牛：
bash
xcowsay --at {{X}},{{Y}}
  • 显示一头不同大小的牛：
bash
xcowsay --cow-size {{small|med|large}}
  • 显示思想泡泡而不是说话泡泡：
bash
xcowsay --think
  • 用指定的照片来代替默认的牛：
bash
xcowsay --image {{路径/到/文件}}
