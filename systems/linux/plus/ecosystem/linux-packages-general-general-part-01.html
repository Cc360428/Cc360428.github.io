Linux：软件安装与包管理 ​

维护 Debian 系软件包与仓库 ​

add-apt-repository（Linux） · apt 仓库管理 ​

更多信息：https://manned.org/add-apt-repository。

  • 添加一个新的 APT 仓库：
bash
add-apt-repository {{指定仓库}}
  • 移除一个 APT 仓库：
bash
add-apt-repository {{[-r|--remove]}} {{指定仓库}}
  • 添加一个仓库并更新缓存：
bash
add-apt-repository --update {{指定仓库}}
  • 允许从指定仓库下载源码：
bash
add-apt-repository {{[-s|--enable-source]}} {{指定仓库}}

aptitude（Linux） · Debian 和 Ubuntu 上的软件包管理工具 ​

更多信息：https://manned.org/aptitude。

  • 同步可用软件包及其版本列表，在运行后续 aptitude 命令前，应该首先运行该命令：
bash
sudo aptitude update
  • 安装一个新的软件包及其依赖：
bash
sudo aptitude install {{软件包}}
  • 查找一个软件包：
bash
aptitude search {{软件包}}
  • 查找一个已安装的软件包（?installed 是一个 aptitude 搜索项）：
bash
aptitude search '?installed({{软件包}})'
  • 移除一个软件包并移除所有依赖它的软件包：
bash
sudo aptitude remove {{软件包}}
  • 更新已安装软件包到最新版本：
bash
sudo aptitude upgrade
  • 更新已安装的软件包（类似于 aptitude upgrade 命令），移除过时的软件包并安装额外的软件包以满足新的软件包依赖项：
bash
sudo aptitude full-upgrade
  • 锁定一个已安装的软件包以便阻止它自动升级：
bash
sudo aptitude hold '?installed({{软件包}})'

oma（Linux） · 一款为使用 dpkg 的发行版打造的软件包管理前端 ​

更多信息：https://github.com/AOSC-Dev/oma#usage。

  • 进入交互式包管理界面：
bash
sudo oma
  • 安装软件包：
bash
sudo oma install {{软件包名}}
  • 移除软件包：
bash
sudo oma remove {{软件包名}}
  • 搜索软件包：
bash
oma search {{关键词}}
  • 显示软件包的详细信息：
bash
oma show
  • 将所有已安装的软件包升级至最新版本：
bash
sudo oma upgrade
  • 更新可用软件包及其版本的列表（执行 oma install 和 oma upgrade 前会自动执行）：
bash
sudo oma refresh
  • 显示帮助：
bash
oma help

维护 Arch 与 AUR 软件包 ​

aura（Linux） · Aura 包管理器：一个安全且支持多语言的 Arch Linux 和 AUR 的包管理器 ​

更多信息：https://github.com/fosskers/aura。

  • 从官方仓库和 AUR 检索包：
bash
aura --aursync --both --search {{包名|正则}}
  • 从 AUR 安装一个软件包：
bash
aura --aursync {{包名}}
  • 以详细模式升级所有的 AUR 包并移除所有的编译依赖：
bash
aura --aursync --diff --sysupgrade --delmakedeps --unsuppress
  • 从官方仓库安装一个软件包：
bash
aura --sync {{包名}}
  • 同步并更新官方仓库的所有软件包：
bash
aura --sync --refresh --sysupgrade
  • 使用包缓存降级一个软件包：
bash
aura --downgrade {{包名}}
  • 移除一个软件包及其依赖：
bash
aura --remove --recursive --unneeded {{包名}}
  • 移除孤儿包（作为依赖安装但现在不被任何包依赖）：
bash
aura --orphans --abandon

auracle（Linux） · 用来和 Arch Linux 用户仓库交互的命令行工具，这个仓库通常被称作 AUR ​

更多信息：https://github.com/falconindy/auracle/blob/master/man/auracle.1.pod。

  • 显示符合一个regex式的 AUR 包：
bash
auracle search '{{regular_expression}}'
  • 显示 AUR 包列表的包信息，包名以一个单独的空格分隔：
bash
auracle info {{package1 package2 ...}}
  • 显示 AUR 包列表的 PKGBUILD 文件（编译信息），包名以一个单独的空格分隔：
bash
auracle show {{package1 package2 ...}}
  • 显示已安装 AUR 包的更新：
bash
auracle outdated

aurman（Linux） · 用来构建和安装 AUR 包的 Arch Linux 实用工具 ​

另请参阅：pacman。 更多信息：https://github.com/polygamma/aurman#syntax。

  • 同步并更新所有包：
bash
aurman {{[-S|--sync]}} {{[-y|--refresh]}} {{[-u|--sysupgrade]}}
  • 同步并更新所有包但不显示 PKGBUILD 文件的变动：
bash
aurman {{[-S|--sync]}} {{[-y|--refresh]}} {{[-u|--sysupgrade]}} --noedit
  • 安装一个新包：
bash
aurman {{[-S|--sync]}} {{包名}}
  • 安装一个新包但不显示 PKGBUILD 文件的变动：
bash
aurman {{[-S|--sync]}} --noedit {{包名}}
  • 无确认提示安装一个新包：
bash
aurman {{[-S|--sync]}} --noedit --noconfirm {{包名}}
  • 在官方仓库和 AUR 的包数据库中查找关键字：
bash
aurman {{[-S|--sync]}} {{[-s|--search]}} {{关键字}}
  • 移除一个包及其依赖：
bash
aurman --remove --recursive --nosave {{包名}}
  • 清除包缓存（用两次 --clean 参数清除所有包缓存）：
bash
aurman {{[-S|--sync]}} {{[-c|--clean]}}

aurvote（Linux） · 为 AUR 中的包投票 ​

为了投票成功，文件 ~/.config/aurvote 必须存在并包含你的 AUR 身份凭证。 更多信息：https://github.com/archlinuxfr/aurvote#name。

  • 交互式创建包含你的 AUR 用户名和密码的 ~/.config/aurvote 文件：
bash
aurvote --configure
  • 为一个或多个 AUR 包投票：
bash
aurvote {{package1 package2 ...}}
  • 为一个或多个 AUR 包取消投票：
bash
aurvote {{[-u|--unvote]}} {{package1 package2 ...}}
  • 检查一个或多个 AUR 包是否已投票：
bash
aurvote {{[-c|--check]}} {{package1 package2 ...}}
  • 查看 aurvote 的帮助信息：
bash
aurvote {{[-h|--help]}}

pacman（Linux） · Arch Linux 的软件包管理器工具 ​

另请参阅：pacman-database，pacman-deptest，pacman-files，pacman-key，pacman-mirrors，pacman-query，pacman-remove，pacman-sync，pacman-upgrade。 更多信息：https://manned.org/pacman.8。

  • 同步并更新所有软件包：
bash
sudo pacman -Syu
  • 安装一个新的软件包：
bash
sudo pacman -S {{软件包}}
  • 删除一个软件包及其依赖：
bash
sudo pacman -Rs {{软件包}}
  • 列出已安装的软件包和版本：
bash
pacman -Q
  • 仅列出明确安装的软件包和版本：
bash
pacman -Qe
  • 查找哪个包拥有某个文件：
bash
pacman -Qo {{文件名}}
  • 清空软件包缓存以释放空间：
bash
sudo pacman -Scc

paru（Linux） · 一个 AUR 助手和 pacman 包装 ​

另请参阅：pacman, yay。 更多信息：https://github.com/Morganamilo/paru#examples。

  • 交互式搜索并安装软件包：
bash
paru {{包名或关键字}}
  • 同步和更新所有包：
bash
paru
  • 更新 AUR 包：
bash
paru -Sua
  • 获取包的信息：
bash
paru -Si {{包}}
  • 从 AUR 或 ABS 下载 PKGBUILD 和其他的包的源文件：
bash
paru --getpkgbuild {{包}}
  • 显示包的 PKGBUILD 文件：
bash
paru --getpkgbuild --print {{包}}

yaourt（Linux） · Arch Linux 中用于从 Arch User Repository 中构建软件包的工具 ​

更多信息：https://archlinux.fr/yaourt-en。

  • 同步并更新所有软件包（包括 AUR）：
bash
yaourt -Syua
  • 安装一个新的软件包（包括 AUR）：
bash
yaourt -S {{软件包}}
  • 移除一个软件包和它的依赖（包括 AUR 软件包）：
bash
yaourt -Rs {{软件包}}
  • 在软件包数据库中搜索一个关键字（包括 AUR）：
bash
yaourt -Ss {{软件包}}
  • 列出已安装的软件包、版本和仓库（AUR 软件包将被列在 'local' 仓库下）：
bash
yaourt -Q

yay（Linux） · Yet Another Yogurt: 一个用于 Arch Linux 的工具，用于从 Arch User Repository 中构建和安装软件包 ​

另请参阅：pacman。 更多信息：https://github.com/Jguer/yay#first-use。

  • 从仓库和 AUR 中交互式搜索和安装软件包：
bash
yay {{软件包|搜索词}}
  • 同步并更新所有来自仓库和 AUR 的软件包：
bash
yay
  • 只同步和更新 AUR 软件包：
bash
yay -Sua
  • 从仓库和 AUR 中安装一个新的软件包：
bash
yay -S {{软件包}}
  • 从仓库和 AUR 中搜索软件包数据库中的关键词：
bash
yay -Ss {{关键词}}
  • 显示已安装软件包和系统健康状况的统计数据：
bash
yay -Ps

维护 RPM 系软件包 ​

dnf（Linux） · RHEL, Fedora 和 CentOS 的软件包管理工具（yum 的替代品） ​

对于其他包管理器中的等效命令，请见 https://wiki.archlinux.org/title/Pacman/Rosetta。 更多信息：https://dnf5.readthedocs.io/en/latest/commands/index.html。

  • 更新已安装的包到最新可用版本：
bash
sudo dnf upgrade
  • 通过关键词搜索包：
bash
dnf search {{关键词1 关键词2 ...}}
  • 显示软件包的描述：
bash
dnf info {{包}}
  • 安装软件包（使用 -y 自动确认所有提示）：
bash
sudo dnf install {{包1 包2 ...}}
  • 删除软件包：
bash
sudo dnf remove {{包1 包2 ...}}
  • 列出已安装的包：
bash
dnf list --installed
  • 查找哪些包提供给定命令：
bash
dnf provides {{命令}}
  • 查看所有过去的操作：
bash
dnf history

zypper（Linux） · SUSE & openSUSE 的软件包管理工具 ​

更多信息：https://en.opensuse.org/SDB:Zypper_manual。

  • 同步可用的软件包和版本列表：
bash
zypper refresh
  • 安装一个新的软件包：
bash
zypper install {{软件包}}
  • 移除一个软件包：
bash
zypper remove {{软件包}}
  • 将已安装的软件包升级到最新的可用版本：
bash
zypper update
  • 通过关键字搜索软件包：
bash
zypper search {{关键字}}
