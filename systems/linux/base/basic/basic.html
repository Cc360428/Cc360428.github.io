Linux 基础命令 ​

示例面向常见 GNU/Linux 发行版。涉及修改的命令先在测试目录验证；需要管理员权限时再使用 sudo。

一、认识当前系统 ​

bash
# 当前用户、用户组和主机
whoami
id
hostname

# 内核、CPU 架构和发行版
uname -a
uname -m
cat /etc/os-release

# 当前时间、时区和运行时长
date --iso-8601=seconds
timedatectl
uptime

/etc/os-release 是判断包管理器和发行版差异的可靠入口。不要只根据内核版本猜测 Ubuntu、Debian、Rocky Linux 或其他发行版。

二、文件与目录 ​

2.1 定位和查看 ​

bash
pwd                         # 当前工作目录
ls                          # 当前目录的非隐藏条目
ls -lah                     # 详细、含隐藏文件、人类可读大小
ls -ld <directory>          # 查看目录本身，而非目录内容
stat <file>                 # 类型、大小、权限、时间戳和 inode
file <file>                 # 根据内容判断文件类型

Linux 路径区分大小写。以 / 开头的是绝对路径；./ 表示当前目录，../ 表示上一级目录。

2.2 创建、复制、移动 ​

bash
mkdir <directory>
mkdir -p <parent>/<child>    # 连同缺失的父目录一起创建
touch <file>                 # 不存在则创建，存在则更新时间戳

cp <source> <destination>
cp -a <source-dir> <destination-dir>  # 递归并尽量保留属性
mv <source> <destination>   # 移动或重命名

覆盖重要文件前先比较并备份：

bash
cmp --silent <source> <destination> || echo '内容不同'
cp -a <destination> "<destination>.bak.$(date +%Y%m%d%H%M%S)"

2.3 删除 ​

bash
rmdir <empty-directory>     # 只删除空目录
rm -i <file>                # 删除前询问
rm -rI <directory>          # 递归删除；批量目标只确认一次

删除前检查

不要把未验证的变量传给 rm -rf。先执行 realpath -- "$target" 和 find -- "$target" -maxdepth 2 -print，确认它不是空值、/、用户主目录或宽泛父目录。删除通常不可恢复。

三、查看和编辑文本 ​

3.1 阅读文件 ​

bash
cat <file>                  # 适合短文件
less <file>                 # 分页查看；/ 搜索，n 下一个，q 退出
head -n 20 <file>           # 前 20 行
tail -n 50 <file>           # 后 50 行
tail -F <log-file>          # 跟踪日志，文件轮转后继续跟踪
wc -l <file>                # 行数
nl -ba <file>               # 显示包括空行在内的行号

tail -F 比 tail -f 更适合会被 logrotate 重建的日志文件。

3.2 搜索内容 ​

bash
grep -n 'ERROR' <file>                    # 行号和匹配行
grep -RIn --exclude-dir=.git 'pattern' .  # 递归搜索
grep -E 'WARN|ERROR' <file>               # 扩展正则
grep -v '^#' <file>                       # 排除注释行

若已安装 ripgrep，代码仓库中通常更快：

bash
rg -n 'pattern' <directory>
rg --files <directory>

3.3 写入与编辑 ​

bash
nano <file>                  # 新手友好的终端编辑器
vim <file>                   # 常见终端编辑器
printf '%s\n' 'one' 'two' > <file>   # 覆盖
printf '%s\n' 'three' >> <file>      # 追加

重定向发生在 sudo 之前

sudo echo value > /etc/file 中的 > 仍由当前 Shell 执行。需要管理员权限时使用 printf '%s\n' value | sudo tee /etc/file。但 tee 会覆盖目标，先备份并确认内容。

四、查找文件 ​

bash
# 按名称、类型和修改时间
find <directory> -type f -name '*.log'
find <directory> -type d -name cache
find <directory> -type f -mtime -1         # 最近 24 小时修改
find <directory> -type f -size +100M       # 大于 100 MiB

# 只列出，确认后再执行后续动作
find <directory> -type f -name '*.tmp' -print

避免一开始就把 -delete 或 -exec rm 加到 find。先用完全相同的筛选条件输出目标，再执行变更。

五、链接与 inode ​

bash
ln -s <target> <link-name>   # 符号链接，可跨文件系统
readlink <link-name>
readlink -f <link-name>      # 解析完整路径
ls -li <file>                # 查看 inode

硬链接 ln <target> <link-name> 与原文件共享 inode，通常不能跨文件系统，也不应用于目录。符号链接保存目标路径；目标被移走后链接会失效。

六、权限、所有者与身份 ​

6.1 读懂权限 ​

ls -l 中的 rwxr-x--- 分为所有者、所属组、其他用户三组：

权限文件目录
r读取内容列出名称
w修改内容创建、删除、重命名条目
x执行文件进入或访问目录中的条目

6.2 修改权限与所有者 ​

bash
chmod u+x <script>           # 给所有者增加执行权限
chmod g-w <file>             # 移除组写权限
chmod 640 <file>             # 所有者 rw，组 r，其他无权限
chmod 750 <directory>        # 所有者 rwx，组 rx，其他无权限

chown <user>:<group> <file>
chgrp <group> <file>
umask                        # 查看新文件默认权限掩码

递归权限修改

不要对应用目录盲目使用 chmod -R 777。文件通常不需要执行位，敏感信息也不应全员可写。确需递归时分别处理目录和文件，并先 find ... -print 检查目标。

6.3 sudo ​

bash
sudo -l                     # 查看当前用户被授权的命令
sudo <command>              # 以管理员权限执行单条命令
sudo -u <user> <command>    # 以指定用户运行

优先给单条命令加 sudo，避免长期停留在 root Shell。

七、进程与作业 ​

bash
ps -ef                      # 全部进程快照
ps aux --sort=-%cpu | head  # CPU 使用较高的进程
pgrep -af '<pattern>'       # PID 和完整命令行
top                         # 动态查看；按 q 退出

<command> &                 # 后台启动
jobs -l                     # 当前 Shell 的作业
fg %1                       # 把 1 号作业切回前台

7.1 发送信号 ​

bash
kill -TERM <pid>            # 请求进程正常退出
kill -HUP <pid>             # 常用于请求重载，实际行为由程序决定
kill -KILL <pid>            # 内核强制终止，无法清理资源

先通过 ps -fp <pid> 确认进程。优先 TERM 并观察退出，只有进程无响应且影响已评估时才使用 KILL。

八、systemd 服务 ​

bash
systemctl status <service> --no-pager
systemctl is-active <service>
systemctl is-enabled <service>
systemctl list-units --type=service --state=running

sudo systemctl start <service>
sudo systemctl stop <service>
sudo systemctl restart <service>
sudo systemctl reload <service>       # 服务必须支持重载
sudo systemctl enable --now <service> # 开机启用并立即启动

修改 Unit 文件后：

bash
sudo systemctl daemon-reload
sudo systemctl restart <service>

重启会造成短暂中断；若服务支持 reload，配置验证通过后优先平滑重载。深入排障见 Linux 进阶命令。

九、磁盘和文件系统 ​

bash
df -hT                       # 已挂载文件系统容量和类型
df -ih                       # inode 使用率
du -sh <directory>           # 目录总大小
du -xhd1 <directory> | sort -h  # 同一文件系统下一级目录大小
lsblk -f                     # 块设备、文件系统和挂载点
findmnt                      # 挂载关系
mountpoint <directory>       # 判断目录是否是挂载点

df 显示文件系统整体用量，du 汇总可遍历的文件。两者差距大时，常见原因是进程仍打开已删除文件、挂载覆盖或权限限制。

文件系统操作

mkfs 会创建文件系统并覆盖设备上的现有数据，dd 指定错误的输入或输出也可能摧毁磁盘。生产环境不要仅凭 /dev/sdX 名称操作设备；先用 lsblk -f、blkid、findmnt 多重确认并执行备份流程。

十、网络基础 ​

bash
ip -brief address            # 网卡和地址概览
ip route                     # 路由表
ss -lntup                    # 监听中的 TCP/UDP 端口及进程
ss -tnp                      # TCP 连接

ping -c 4 <host>             # ICMP 连通性，不代表应用一定可用
getent hosts <hostname>      # 按系统 NSS 配置解析主机名
dig <domain> A               # DNS 详细查询，需要 dnsutils/bind-utils
curl -I --max-time 10 https://<host>/  # 仅取 HTTP 响应头
curl -v --max-time 10 https://<host>/  # DNS、连接、TLS 和 HTTP 细节

确认某端口由哪个进程监听：

bash
sudo ss -lntp 'sport = :<port>'
sudo lsof -nP -iTCP:<port> -sTCP:LISTEN

不要把 ping 成功等同于端口开放，也不要把 ping 失败直接等同于主机宕机；防火墙可能只禁止 ICMP。

十一、归档、压缩与校验 ​

bash
# tar：先列出，再解压
tar -tzf <archive.tar.gz>
tar -xzf <archive.tar.gz> -C <destination>
tar -czf <archive.tar.gz> <directory>

# zip
unzip -l <archive.zip>
unzip <archive.zip> -d <destination>
zip -r <archive.zip> <directory>

# 摘要校验
sha256sum <file>
sha256sum -c <checksums-file>

解压不可信归档前先列出内容，警惕绝对路径和 ../ 路径穿越；在新建的隔离目录中解压。

十二、软件包管理 ​

12.1 Debian 与 Ubuntu：APT ​

bash
sudo apt update
apt list --upgradable
apt show <package>
sudo apt install <package>
sudo apt remove <package>

12.2 Fedora、RHEL、Rocky Linux：DNF ​

bash
sudo dnf check-update
dnf info <package>
sudo dnf install <package>
sudo dnf remove <package>

12.3 查询文件属于哪个包 ​

bash
dpkg -S <path>               # Debian/Ubuntu，针对已安装包
rpm -qf <path>               # RPM 系发行版

升级生产主机前确认仓库来源、变更窗口、依赖影响和回滚路径。不要把不同发行版的仓库配置混用。

十三、用户和用户组 ​

bash
getent passwd <user>
getent group <group>
groups <user>
last -n 20
who
w

用户创建、删除、密码和 SSH 授权属于安全变更，应遵循公司的身份和权限流程，不在共享文档记录真实密码或私钥。

十四、环境变量与 Shell ​

bash
env                           # 当前环境
printenv PATH
export APP_ENV=staging        # 仅当前 Shell 及其子进程
unset APP_ENV
command -v <command>          # 命令解析到哪里
type <command>                # 别名、函数、内建或可执行文件
history                       # 历史可能包含敏感信息

单次命令临时设置变量：

bash
APP_ENV=staging <command>

不要把 Token 直接写入命令行；命令参数和环境变量可能被历史、日志、进程检查或崩溃报告捕获。优先使用工具支持的凭据文件、系统密钥服务或交互式标准输入。

十五、管道与重定向入门 ​

bash
<command> > <file>            # 覆盖标准输出
<command> >> <file>           # 追加标准输出
<command> 2> <error-file>     # 标准错误
<command> > <file> 2>&1       # 标准输出与错误都进入同一文件
<command-1> | <command-2>     # 前者输出成为后者输入

示例：统计访问日志中状态码的数量。

bash
awk '{print $9}' <access-log> | sort | uniq -c | sort -nr

管道默认可能只返回最后一个命令的退出码。脚本中可启用 set -o pipefail，让上游失败也使管道失败；详见 Linux 进阶命令。

十六、日常自检清单 ​

bash
id
hostname
pwd
df -hT
free -h
uptime
systemctl --failed
ss -lntup

这组命令只提供概览，不足以独立判断故障原因。观察到异常后，应结合时间范围、业务现象、日志和基线继续定位。
