Windows 网络与监听诊断命令 ​

网络连接与传输 ​

检查状态与定位问题 ​

pathping（Windows） · 一种结合了ping和tracert功能的跟踪路由工具 ​

一种结合了ping和tracert功能的跟踪路由工具。 更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/pathping。

  • Ping 并追踪主机的路由：
bash
pathping {{主机名}}
  • 不要对主机名执行 IP 地址的反向查找：
bash
pathping {{主机名}} -n
  • 指定要搜索目标的最大跃点数（默认值为 30）：
bash
pathping {{主机名}} -h {{最大跃点数}}
  • 指定 ping 之间等待的毫秒数（默认值为 240）：
bash
pathping {{主机名}} -p {{时间}}
  • 指定每跳的查询数（默认值为 100）：
bash
pathping {{主机名}} -q {{查询语句}}
  • 强制使用 IPV4：
bash
pathping {{主机名}} -4
  • 强制使用 IPV6：
bash
pathping {{主机名}} -6
  • 显示详细的使用帮助：
bash
pathping /?

systeminfo（Windows） · 显示本地或远程计算机的操作系统配置 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/systeminfo。

  • 显示本地计算机的操作系统配置：
bash
systeminfo
  • 以指定的输出格式显示系统配置：
bash
systeminfo /fo {{table|list|csv}}
  • 显示远程计算机的系统配置：
bash
systeminfo /s {{远程主机名}} /u {{用户名}} /p {{密码}}
  • 显示详细的帮助信息：
bash
systeminfo /?

专用工具与其他操作 ​

cmstp（Windows） · 用于管理连接服务配置文件的命令行工具 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/cmstp。

  • 安装指定的配置文件：
bash
cmstp "{{配置文件的路径}}"
  • 安装时不创建桌面快捷方式：
bash
cmstp /ns "{{配置文件的路径}}"
  • 安装时不检查依赖：
bash
cmstp /nf "{{配置文件的路径}}"
  • 仅为当前用户安装：
bash
cmstp /su "{{配置文件的路径}}"
  • 为所有用户安装（需要管理员权限）：
bash
cmstp /au "{{配置文件的路径}}"
  • 静默安装：
bash
cmstp /s "{{配置文件的路径}}"
  • 卸载一个指定的配置文件：
bash
cmstp /u "{{配置文件的路径}}"
  • 静默删除：
bash
cmstp /u /s "{{配置文件的路径}}"

ftp（Windows） · 在本地和远程 FTP 服务器之间交互式传输文件 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/ftp。

  • 交互式连接一个远程的 FTP 服务：
bash
ftp {{主机名}}
  • 匿名登录：
bash
ftp -A {{主机名}}
  • 初始连接时禁用自动登录：
bash
ftp -n {{主机名}}
  • 运行包含 FTP 命令列表的文件：
bash
ftp -s:{{文件的路径}} {{主机名}}
  • 下载多个文件（通配符表达式）：
bash
mget {{*.png}}
  • 上传多个文件（通配符表达式）：
bash
mput {{*.zip}}
  • 在远程服务器上删除多个文件：
bash
mdelete {{*.txt}}
  • 显示详细的帮助：
bash
ftp -?

getmac（Windows） · 显示系统的 MAC 地址 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/getmac。

  • 显示当前系统的 MAC 地址：
bash
getmac
  • 以特定格式显示详细信息：
bash
getmac /fo {{table|list|csv}}
  • 排除输出列表中的标题：
bash
getmac /nh
  • 显示一个远程主机的 MAC 地址：
bash
getmac /s {{主机名}} /u {{用户名}} /p {{密码}}
  • 详细显示 MAC 地址信息：
bash
getmac /v
  • 显示详细的帮助信息：
bash
getmac /?

ipconfig（Windows） · 显示和管理 Windows 的网络配置 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/ipconfig。

  • 显示网络适配器列表：
bash
ipconfig
  • 显示网络适配器的详细列表：
bash
ipconfig /all
  • 为一个网络适配器重新获取 IP 地址：
bash
ipconfig /renew {{适配器}}
  • 为一个网络适配器释放 IP 地址：
bash
ipconfig /release {{适配器}}
  • 显示所有本地 DNS 缓存：
bash
ipconfig /displaydns
  • 清除所有本地 DNS 缓存：
bash
ipconfig /flushdns

rdpsign（Windows） · 用于签名远程桌面协议（RDP）文件的工具 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/rdpsign。

  • 为一个 RDP 文件签名：
bash
rdpsign /sha256 {{签名证书指纹}} {{文件路径.rdp}}
  • 使用一个指定的 sha256 哈希值为 RDP 文件签名：
bash
rdpsign /sha256 {{签名证书指纹}} {{文件路径.rdp}}
  • 启用静默输出：
bash
rdpsign /sha256 {{签名证书指纹}} /q {{文件路径.rdp}}
  • 显示详细的信息、警告和状态：
bash
rdpsign /sha256 {{签名证书指纹}} /v {{文件路径.rdp}}
  • 在不更新文件的情况下将输出显示到标准输出来测试签名：
bash
rdpsign /sha256 {{签名证书指纹}} /l {{文件路径.rdp}}

wget（Windows） · 在 PowerShell 中，当原始 wget 程序（<https://www.gnu.org/software/wget>）未正确安装时，此命令可能是 Invoke-WebRequest 的别名 ​

在 PowerShell 中，当原始 wget 程序（https://www.gnu.org/software/wget）未正确安装时，此命令可能是 Invoke-WebRequest 的别名。 注意：如果 version 命令返回错误，则 PowerShell 可能已将此命令替换为 Invoke-WebRequest。 更多信息：https://learn.microsoft.com/powershell/module/microsoft.powershell.utility/invoke-webrequest。

  • 查看原始 wget 命令的文档：
bash
tldr wget {{[-p|--platform]}} common
  • 查看 PowerShell 的 Invoke-WebRequest 命令的文档：
bash
tldr invoke-webrequest
  • 显示版本：
bash
wget --version

Windows 端口、服务与 DNS 操作 ​

关闭端口号 ​

先读取监听及 PID：

cmd
netstat -ano | findstr 8080

findstr 的子串命中不是精确端口确认；还须核对本地地址列、监听状态和当前进程身份。原 PID 6148 只是历史现场值，不可复制用于当前主机；停止应通过所属服务或对确认对象操作。

关闭服务 ​

原记录曾停止 wuauserv（Windows Update），这不属于端口诊断，也不应作为默认修复。需变更时先确认具体服务、依赖和维护安排。

查看Windows 自启程序 ​

msconfig

查看hosts ​

shell
C:\Windows\System32\drivers\etc

刷新 DNS 解析缓存 ​

cmd
ipconfig /flushdns
