Windows 终端与会话命令 ​

终端、会话与日常操作 ​

环境、会话与自动执行 ​

Clear-History（Windows） · 删除 PowerShell 会话命令历史记录中的条目 ​

注意：clhy 可以作为 Clear-History 的别名使用。 更多信息：https://learn.microsoft.com/powershell/module/microsoft.powershell.core/clear-history。

  • 清除当前会话中的所有命令历史记录：
bash
Clear-History
  • 按指定名称清除命令：
bash
Clear-History -CommandLine "{{命令}}"
  • 按名称清除多个命令：
bash
Clear-History -CommandLine {{"命令1", "命令2", ...}}
  • 按 ID 清除指定历史记录条目：
bash
Clear-History -Id {{ID_编号}}
  • 清除多个 ID：
bash
Clear-History -Id {{id1, id2, ...}}
  • 清除 ID 范围内的命令：
bash
Clear-History -Id ({{起始_ID}}..{{结束_ID}})
  • 显示将被删除的内容：
bash
Clear-History -WhatIf
  • 清除前请求确认：
bash
Clear-History -Confirm

cls（Windows） · 清屏 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/cls。

  • 清屏：
bash
cls

color（Windows） · 设置控制台的前景色和背景色 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/color。

  • 将控制台颜色恢复至默认值：
bash
color
  • 列出可用的颜色值和详细信息：
bash
color /?
  • 将控制台前景色和背景色设置为指定颜色：
bash
color {{背景色值}}{{前景色值}}

exit（Windows） · 退出当前的命令行实例或 bat 脚本 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/exit。

  • 退出当前的命令行实例：
bash
exit
  • 退出当前的 [b]at 脚本：
bash
exit /b
  • 使用一个指定的退出码退出：
bash
exit {{退出码}}

专用工具与其他操作 ​

cmd（Windows） · Windows 命令解释器 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/cmd。

  • 开启一个新的命令行实例：
bash
cmd
  • 运行指定的命令然后退出：
bash
cmd /c {{echo 已执行cmd命令}}
  • 执行一个指定的命令，之后进入一个交互式 shell：
bash
cmd /k {{echo 已执行cmd命令}}
  • 关闭命令回显；程序自身的输出仍会显示：
bash
cmd /q
  • 启用或禁用 !变量! 形式的延迟环境变量展开：
bash
cmd /v:{{on|off}}
  • 启用或禁用命令扩展：
bash
cmd /e:{{on|off}}
  • 强制输出内容使用 Unicode 编码：
bash
cmd /u

doskey（Windows） · 管理宏，Windows 命令和命令行 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/doskey。

  • 列出可用的宏：
bash
doskey /macros
  • 创建一个新的宏：
bash
doskey {{宏的名称}}={{命令}}
  • 为指定可执行文件创建新的宏：
bash
doskey /exename={{可执行文件名}} {{宏的名称}}={{命令}}
  • 删除一个宏：
bash
doskey {{宏的名称}}=
  • 列出所有储存在内存中的命令：
bash
doskey /history
  • 将宏保存到文件以便于移植：
bash
doskey /macros > {{保存宏的文件名}}
  • 从文件中加载宏：
bash
doskey /macrofile={{保存宏的文件名}}

logoff（Windows） · 注销登录会话 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/logoff。

  • 注销当前会话：
bash
logoff
  • 通过名称和 ID 注销会话：
bash
logoff {{会话名|会话id}}
  • 在通过 RDP 连接的特定服务器上注销会话：
bash
logoff {{会话名|会话id}} /server:{{服务器名}}

set（Windows） · 显示或设置当前命令行实例的环境变量 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/set。

  • 列出当前所有环境变量：
bash
set
  • 为一个环境变量设置指定的值：
bash
set {{变量名}}={{值}}
  • 列出以指定字符串开头的环境变量：
bash
set {{变量名}}
  • 提示用户输入指定变量的值：
bash
set /p {{变量名}}={{提示信息}}

shutdown（Windows） · 用于关闭、重启或注销计算机的工具 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/shutdown。

  • 关闭当前计算机：
bash
shutdown /s
  • 强制关闭当前计算机的所有应用程序：
bash
shutdown /s /f
  • 立即重启当前计算机：
bash
shutdown /r /t 0
  • 休眠当前计算机：
bash
shutdown /h
  • 注销当前计算机：
bash
shutdown /l
  • 指定在关闭前等待的秒数：
bash
shutdown /s /t {{秒}}
  • 中止尚未超时的关机序列：
bash
shutdown /a
  • 关闭远程计算机：
bash
shutdown /s /m {{\\主机名}}

title（Windows） · 设置命令提示符窗口的标题 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/title。

  • 设置当前的命令提示符窗口的标题：
bash
title {{新标题}}

tzutil（Windows） · 用于显示或配置系统时区的工具 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/tzutil。

  • 获取当前的时区：
bash
tzutil /g
  • 显示可用的时区列表：
bash
tzutil /l
  • 将系统时区设置为特定值：
bash
tzutil /s {{时区 id}}

ver（Windows） · 显示当前 Windows 或 MS-DOS 的版本号 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/ver。

  • 显示当前版本号：
bash
ver

vol（Windows） · 显示有关卷的信息 ​

更多信息：https://learn.microsoft.com/windows-server/administration/windows-commands/vol。

  • 显示当前驱动器的标签和序列号：
bash
vol
  • 显示指定驱动器的标签和序列号：
bash
vol {{D:}}

wsl（Windows） · 从命令行管理适用于 Linux 的 Windows 子系统 ​

更多信息：https://learn.microsoft.com/windows/wsl/reference。

  • 启动 Linux Shell（在默认发行版中）：
bash
wsl {{shell_命令}}
  • 在不使用 Shell 的情况下运行 Linux 命令：
bash
wsl {{[-e|--exec]}} {{命令}} {{命令参数}}
  • 指定特定的发行版：
bash
wsl {{[-d|--distribution]}} {{发行版}} {{shell_命令}}
  • 列出所有可用发行版：
bash
wsl {{[-l|--list]}}
  • 将发行版导出到 .tar 文件：
bash
wsl --export {{发行版}} {{路径\distro_fs.tar}}
  • 从 .tar 文件导入发行版：
bash
wsl --import {{发行版}} {{路径\安装位置}} {{路径\distro_fs.tar}}
  • 更改指定发行版的版本：
bash
wsl --set-version {{发行版}} {{版本}}
  • 关闭适用于 Linux 的 Windows 子系统：
bash
wsl --shutdown

Windows CMD 目录切换 ​

Windows 终端 ​

cd ​

  • 进入文件
cmd
C:\Users\admin>cd Hyper
  • 切换磁盘
cmd
C:\Users\admin\Hyper>cd /d D:\
D:\>
  • 返回上一级目录
cmd
C:\Users\admin\Hyper>cd ..
C:\Users\admin>
