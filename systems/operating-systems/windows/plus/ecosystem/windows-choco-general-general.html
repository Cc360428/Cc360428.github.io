choco 工具使用（Windows） ​

版本前置：本页部分例子来自 Chocolatey 1.x。2.x 起 choco list 只列本地已安装包，去掉 --local-only；远程查询改用 choco search。下面凡含 --local-only、远程 list、--allow-multiple 的行按旧版记录阅读，实际参数先核对目标版本帮助与官方迁移说明。

检查状态与定位问题 ​

choco info（Windows） · 显示有关 Chocolatey 包的详细信息 ​

更多信息：https://docs.chocolatey.org/en-us/choco/commands/info/。

  • 显示指定包的信息：
bash
choco info {{包名}}
  • 显示一个本地已安装包的信息：
bash
choco info {{包名}} {{[-l|--local-only]}}
  • 从一个自定义的源来获取包的信息：
bash
choco info {{包名}} {{[-s|--source]}} {{源url|别名}}
  • 提供一个用户名和密码来进行验证：
bash
choco info {{包名}} {{[-u|--user]}} {{用户名}} {{[-p|--password]}} {{密码}}

choco list（Windows） · 使用 Chocolatey 显示包列表 ​

更多信息：https://docs.chocolatey.org/en-us/choco/commands/list/。

  • 列出所有可用的软件包：
bash
choco list
  • 列出所有本地已安装的软件包：
bash
choco list --local-only
  • 列出包含本地程序的软件包：
bash
choco list {{[-i|--include-programs]}}
  • 仅列出已批准的软件包：
bash
choco list --approved-only
  • 从指定的源列出软件包：
bash
choco list {{[-s|--source]}} {{源url|别名}}
  • 提供用户名和密码进行身份验证：
bash
choco list --user {{用户名}} --password {{密码}}

choco outdated（Windows） · 使用 Chocolatey 检查过时的包 ​

更多信息：https://docs.chocolatey.org/en-us/choco/commands/outdated/。

  • 用表格的形式列出过时的包：
bash
choco outdated
  • 忽略输出中的固定包：
bash
choco outdated --ignore-pinned
  • 从自定义的源处检查过时的包：
bash
choco outdated {{[-s|--source]}} {{源url|别名}}
  • 提供一个用户名和密码来进行验证：
bash
choco outdated {{[-u|--user]}} {{用户名}} {{[-p|--password]}} {{密码}}

choco search（Windows） · 使用 Chocolatey 搜索一个本地或远程的包 ​

更多信息：https://docs.chocolatey.org/en-us/choco/commands/search/。

  • 搜索一个包：
bash
choco search {{查询语句}}
  • 搜索一个本地的包：
bash
choco search {{查询语句}} --local-only
  • 只显示包含完全匹配的结果：
bash
choco search {{查询语句}} {{[-e|--exact]}}
  • 自动确认所有提示：
bash
choco search {{查询语句}} {{[-y|--yes]}}
  • 从自定义的源处搜索包：
bash
choco search {{查询语句}} {{[-s|--source]}} {{源url|别名}}
  • 提供一个用户名和密码来进行验证：
bash
choco search {{查询语句}} {{[-u|--user]}} {{用户名}} {{[-p|--password]}} {{密码}}

创建、修改与转换 ​

choco install（Windows） · 使用 Chocolatey 下载一个或多个包 ​

更多信息：https://docs.chocolatey.org/en-us/choco/commands/install/。

  • 安装一个或多个用空格分隔的软件包：
bash
choco install {{包名 包名 ..}}
  • 从一个自定义的配置文件中安装包：
bash
choco install {{配置文件的路径}}
  • 安装一个特定的 .nuspec 或 .nupkg 文件：
bash
choco install {{文件的路径}}
  • 安装一个指定版本的包：
bash
choco install {{包名}} --version {{版本号}}
  • 允许安装一个包的多个版本：
bash
choco install {{包名}} --allow-multiple
  • 自动确认所有提示：
bash
choco install {{包名}} {{[-y|--yes]}}
  • 从自定义的源处获取包：
bash
choco install {{包名}} {{[-s|--source]}} {{源url|别名}}
  • 提供一个用户名和密码来进行验证：
bash
choco install {{包名}} {{[-u|--user]}} {{用户名}} {{[-p|--password]}} {{密码}}

choco uninstall（Windows） · 使用 Chocolatey 卸载一个或多个包 ​

更多信息：https://docs.chocolatey.org/en-us/choco/commands/uninstall/。

  • 卸载一个或多个用空格分隔的软件包：
bash
choco uninstall {{包名 『包名』 ..}}
  • 卸载一个指定版本的包：
bash
choco uninstall {{包名}} --version {{版本号}}
  • 自动确认所有提示：
bash
choco uninstall {{包名}} {{[-y|--yes]}}
  • 卸载时同时删除其所有的依赖：
bash
choco uninstall {{包名}} {{[-x|--remove-dependencies]}}
  • 卸载全部包：
bash
choco uninstall all

choco upgrade（Windows） · 使用 Chocolatey 升级一个或多个包 ​

更多信息：https://docs.chocolatey.org/en-us/choco/commands/upgrade/。

  • 升级一个或多个用空格分隔的软件包：
bash
choco upgrade {{包名 包名 ..}}
  • 将一个包升级到指定版本：
bash
choco upgrade {{包名}} --version {{版本号}}
  • 升级全部包：
bash
choco upgrade all
  • 升级除指定的用逗号分隔的包之外的所有包：
bash
choco upgrade all --except "{{包名 , 包名 ..}}"
  • 自动确认所有提示：
bash
choco upgrade {{包名}} {{[-y|--yes]}}
  • 从自定义源处升级包：
bash
choco upgrade {{包名}} {{[-s|--source]}} {{源url|别名}}
  • 提供一个用户名和密码来进行验证：
bash
choco upgrade {{包}} {{[-u|--user]}} {{用户名}} {{[-p|--password]}} {{密码}}

专用工具与其他操作 ​

choco（Windows） · Chocolatey 包管理器的命令行界面 ​

此命令也有关于其子命令的文件，例如：install。 更多信息：https://docs.chocolatey.org/en-us/choco/commands/。

  • 执行 Chocolatey 命令：
bash
choco {{命令}}
  • 显示基本的帮助页面：
bash
choco -?
  • 显示指定命令的帮助页面：
bash
choco {{命令}} -?
  • 显示 Chocolatey 的版本：
bash
choco --version

choco feature（Windows） · Chocolatey 的交互功能 ​

更多信息：https://docs.chocolatey.org/en-us/choco/commands/feature/。

  • 显示可用的功能列表：
bash
choco feature list
  • 启用一个功能：
bash
choco feature enable {{[-n|--name]}} {{功能名称}}
  • 禁用一个功能：
bash
choco feature disable {{[-n|--name]}} {{功能名称}}

choco new（Windows） · 使用 Chocolatey 生成新的包规范文件 ​

更多信息：https://docs.chocolatey.org/en-us/create/commands/new/。

  • 创建一个新的包框架：
bash
choco new {{包名}}
  • 创建一个新的指定版本的包：
bash
choco new {{包名}} --version {{版本号}}
  • 创建一个新的包并指定维护者的名字：
bash
choco new {{包名}} --maintainer {{维护者名字}}
  • 在指定目录下创建新的包：
bash
choco new {{包名}} {{[--out|--output-directory]}} {{指定的目录路径}}
  • 创建一个新的包并指定其 32 位版和 64 位版的安装 URL：
bash
choco new {{package_name}} url="{{url}}" url64="{{url}}"

choco pack（Windows） · 将 .nuspec 打包到已编译的 .nupkg ​

将 .nuspec 打包到已编译的 .nupkg。 更多信息：https://docs.chocolatey.org/en-us/create/commands/pack/。

  • 将 .nuspec 打包到已编译的 .nupkg：
bash
choco pack {{nuspec 的路径}}
  • 将 .nuspec 打包到已编译的 .nupkg, 并指定生成的版本：
bash
choco pack {{nuspec 的路径}} --version {{版本号}}
  • 将 .nuspec 打包到已编译的 .nupkg, 并输出到指定的目录：
bash
choco pack {{nuspec 的路径}} {{[--out|--output-directory]}} {{输出目录的路径}}

choco pin（Windows） · 使用 Chocolatey 将一个包固定到指定的版本 ​

被固定版本的包会在更新时自动忽略。 更多信息：https://docs.chocolatey.org/en-us/choco/commands/pin/。

  • 显示被固定的包以及他们对应的版本号：
bash
choco pin list
  • 将一个包固定至当前版本：
bash
choco pin add {{[-n|--name]}} {{包名}}
  • 将一个包固定直指定的版本：
bash
choco pin add {{[-n|--name]}} {{包名}} --version {{版本号}}
  • 移除指定包的固定状态：
bash
choco pin remove {{[-n|--name]}} {{包名}}

choco source（Windows） · 使用 Chocolatey 管理包的源 ​

更多信息：https://docs.chocolatey.org/en-us/choco/commands/source/。

  • 列出当前可用的源：
bash
choco source list
  • 添加一个新的包源：
bash
choco source add {{[-n|--name]}} {{名称}} {{[-s|--source]}} {{url}}
  • 添加包含凭据的新包源：
bash
choco source add {{[-n|--name]}} {{名称}} {{[-s|--source]}} {{url}} {{[-u|--user]}} {{用户名}} {{[-p|--password]}} {{密码}}
  • 使用客户端证书添加新的包源：
bash
choco source add {{[-n|--name]}} {{名称}} {{[-s|--source]}} {{url}} --cert {{证书的路径}}
  • 启用一个包源：
bash
choco source enable {{[-n|--name]}} {{名称}}
  • 禁用一个包源：
bash
choco source disable {{[-n|--name]}} {{名称}}
  • 移除一个包源：
bash
choco source remove {{[-n|--name]}} {{名称}}
