Hyper-V 安装 CentOS 7 记录 ​

本文是 CentOS 7 环境的历史操作与截图，IP、网卡名和网关均依赖原网络。

  • 需要先下载好 Centos 7 镜像
  • 阿里云地址

创建Linux启动 ​

以下按原截图整理历史创建参数，并非当前机器的推荐规格。先按下一节准备好虚拟交换机，再在创建向导中选择它。

  1. 在 Windows 搜索并打开“Hyper-V 管理器”，选中宿主，在右侧依次点“新建”→“虚拟机”，进入向导后点“下一页”（图 1–3）。
  2. 在“指定名称和位置”填写虚拟机名称；原图将存储位置设为 D:\ProgramData\Microsoft\Windows\Hyper-V\。在“指定代数”选择“第一代”（图 4–5）。
  3. 将启动内存设为 4096 MB，勾选“为此虚拟机使用动态内存”；“配置网络”选择原环境的交换机 demo（图 6–7）。
  4. 选择“创建虚拟硬盘”，原图为 127 GB、动态扩展的 VHDX。“安装选项”选择“从可启动的 CD/DVD-ROM 安装操作系统”→“映像文件(.iso)”，浏览到已下载的 CentOS-7-x86_64-DVD-2009.iso（图 8–9）。
  5. 在摘要核对名称、第一代、4096 MB、交换机、磁盘和 ISO 路径，再点“完成”；列表中出现新虚拟机、状态为“关机”，表示虚拟机定义已创建，不代表客体系统已安装（图 10–11）。

网络管理 ​

先区分 Windows 宿主、虚拟交换机和 Linux 客体。在管理器右侧打开“虚拟交换机管理器”，选择“外部”并点“创建虚拟交换机”（图 1）。原图的交换机名为 demo，连接类型为“外部网络”，绑定宿主物理网卡 Realtek PCIe GbE Family Controller，然后点“应用”（图 2）。这是原宿主的网卡名称；新环境须选择实际接入目标网络的宿主网卡，不能用客体网卡名替代。

基础设置 ​

右键新虚拟机，打开“设置”，在“网络适配器”中将“虚拟交换机”选为已创建的 demo。原设置图还显示 4096 MB 内存和 8 个虚拟处理器；创建向导截图没有展示处理器调整过程。

CentosEnter ​

原图依次是：右键虚拟机点“连接”→在连接窗口点“启动”→在已安装的 CentOS 7 GRUB 菜单选择内核并回车→使用安装时设置的账号和密码登录。图 3 已是硬盘系统的启动菜单，并未展示从空磁盘运行 CentOS 安装器、分区、选择软件及设置账号的过程；本记录不能替代完整安装教程。

  • 网络设置

图 5 打开 /etc/sysconfig/network-scripts/ifcfg-eth0；图 6 实际显示 NAME=eth0、DEVICE=eth0、BOOTPROTO=dhcp、ONBOOT=yes。图 7 的 ifconfig 显示原机 eth0 地址为 192.0.2.10、掩码为 255.255.255.0，未显示默认网关。图 8 记录了当时使用 SSH 登录该地址；首次连接时应独立核对目标主机指纹，不能仅因原图输入了 yes 就跳过身份确认。

以下保留原文另一段配置转录，它与截图不一致，不是可复制模板：文件名为 ifcfg-eth0，而 NAME/DEVICE 是 ens34；BOOTPROTO=dhcp 又混入静态地址；ONBOOT=no 不会按该配置开机激活。192.0.2.10/24 的 .255 是广播地址，不能作普通网关，文档示例地址不用于真实部署。应按真实接口、地址来源和网关重新制定。这些历史截图展示了当时的设置和会话，不证明当前环境连通。

shell
vi /etc/sysconfig/network-scripts/ifcfg-eth0
shell
TYPE=Ethernet                             # 网卡类型：为以太网
PROXY_METHOD=none                         # 代理方式：关闭状态
BROWSER_ONLY=no                           # 只是浏览器：否
BOOTPROTO=dhcp                            # 使用 DHCP；RHEL 7 静态配置示例使用 none 并另设地址
DEFROUTE=yes                              # 允许此连接提供默认路由
IPV4_FAILURE_FATAL=no                     # 是不开启IPV4致命错误检测：否
IPV6INIT=yes                              # IPV6是否自动初始化: 是；是否启用及其影响需按真实IPv6网络核对
IPV6_AUTOCONF=yes                         # IPV6是否自动配置：是；是否启用及其影响需按真实IPv6网络核对
IPV6_DEFROUTE=yes                         # IPV6是否可以为默认路由：是；是否启用及其影响需按真实IPv6网络核对
IPV6_FAILURE_FATAL=no                     # 是不开启IPV6致命错误检测：否
IPV6_ADDR_GEN_MODE=stable-privacy         # IPV6地址生成模型：stable-privacy [这只一种生成IPV6的策略]
NAME=ens34                                # 连接配置名称；与原截图的 eth0 不同
UUID=8c75c2ba-d363-46d7-9a17-6719934267b7 # 原连接配置的 UUID，不作为新连接的通用值
DEVICE=ens34                              # 绑定的设备名，应匹配实际接口；NAME 不要求与其同名
ONBOOT=no                                 # 系统启动时是否设置此网络接口，设置为yes时，系统启动时激活此设备
IPADDR=192.0.2.10                       # 网卡对应的ip地址
PREFIX=24                                 # 子网 24就是255.255.255.0
GATEWAY=192.0.2.10                     # 网关
DNS1=114.114.114.114                      # dns
HWADDR=02:00:00:00:00:01                  # mac地址
