redis 安装 ​

  • 解压：tar zxvf redis-4.0.10.tar.gz
  • 移动到： mv redis-4.0.10 /usr/local/
  • 切换到：cd /usr/local/redis-4.0.10/
  • 编译测试 sudo make test
  • 编译安装 sudo make install
  • 脚本
