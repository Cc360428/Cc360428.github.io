    查看与管理分支；创建、切换与重命名分支；稀疏检出与暂存区导出。

    7 个命令

    查看与管理分支

    git branch管理分支

    创建、切换与重命名分支

    git checkout切换分支或将文件检出到工作区git create-branch在 Git 仓库中创建分支git rename-branch重新命名一个 Git 分支git switch切换 Git 分支。要求 Git 版本在 2.23 以上

    稀疏检出与暂存区导出

    git checkout-index将文件从暂存区复制到工作区git sparse-checkout仅检出仓库的部分文件，而不是克隆或检出全部文件（稀疏检出）
  • Git 合并与撤销Git任务与配置

    合并、变基与补丁；撤销、恢复与清理。

    4 个命令

    合并、变基与补丁

    git cherry-pick将现有提交的变更应用到当前分支git merge合并分支git rebase在新基点上逐个重放提交

    撤销、恢复与清理

    git-revert新建一个反向提交来撤销已有提交，适合已经共享的历史。操作前确认工作区干净；合并提交需额外指定主线

    56 个命令

    初始化仓库与查阅命令帮助

    git分布式版本控制系统git help显示 Git 的帮助信息git init初始化新的本地 Git 仓库git config管理 Git 仓库的自定义设置项git alias为 Git 命令创建快捷方式git annex用 Git 管理文件，但不将其内容提交到版本库中git bug一个使用 Git 内部存储的分布式问题追踪器，不会在项目中添加额外文件git bugreport收集系统和用户的调试信息，生成文本文件以帮助报告 Git 中的问题

    配置凭据和缓存方式

    git credential用于管理和存储 Git 用户凭证（如用户名和密码）git credential-cacheGit 凭证缓存助手，用于在内存中临时存储密码git credential-storeGit 凭证存储助手，用于将密码存储在磁盘上

    查看工作区、暂存与提交

    git status展示 Git 仓库中文件的变更情况git diff显示已跟踪文件的内容变更git 提交前检查提交代码前，检查变更内容、暂存区和空白错误git add将更改的文件添加到索引（暂存区）git rm从仓库索引和本地文件系统中删除文件git commit将文件提交到仓库git coauthor为最新提交添加共同作者（会重写 Git 历史，已共享时需先确认历史改写约定）git cp复制 Git 仓库中的文件并保留历史记录

    交接仓库、应用补丁与检查分支提交

    git bundle将对象和引用打包成归档文件git am应用补丁文件并创建提交。在通过电子邮件接收提交时非常有用git apply将补丁应用到文件和/或暂存区，但不创建提交git cherry查找尚未应用到上游分支的提交

    恢复内容、回退提交与清理未跟踪文件

    git-restore从暂存区或指定提交恢复文件。覆盖工作区文件会丢弃该文件未提交的修改，先用 git diff 核对git reset撤销提交或取消暂存，将当前 Git HEAD 重置到指定状态git-reflog查看本地分支或 HEAD 的移动记录，找回误重置前的提交哈希；记录可能过期，且不是远程备份git clean从工作区删除未被 Git 跟踪的文件git clear将 Git 工作目录清理至如同刚克隆时的状态（包含 .gitignore 中的文件）git clear-soft将 Git 工作目录清理至如同刚克隆时的状态（不包含 .gitignore 中的文件）

    定位历史、责任行与回归提交

    git log查看提交历史git blame显示文件每一行的最后修改者和提交哈希值git annotate显示文件中每一行的提交哈希值和最后修改作者git bisect使用二分查找定位引入错误的提交git commits-since显示从指定时间点以来的提交记录git authors生成 Git 仓库的提交者列表git contrib显示指定作者的提交记录git count统计提交总数git changelog从仓库提交和标签生成变更日志报告git cliff高度可定制的变更日志生成工具git check-mailmap显示联系人的规范名称和电子邮件地址

    导出代码与打开协作界面

    git archive从代码树创建文件归档git archive-file将当前 Git 分支的所有文件导出为 Zip 压缩包git browse在默认浏览器中查看上游代码库git browse-ci在默认浏览器中打开当前 git 代码库的 CI 网站git brv按最后提交日期排序显示分支列表git cola功能强大且界面直观的 Git 图形化界面工具git bulk批量操作多个 Git 仓库git blame-someone-else将你的糟糕代码归咎于其他人

    检查对象、引用与底层提交结构

    git check-attr检查每个路径的文件属性状态（未指定/已设置/未设置）git check-ignore分析和调试 Git 忽略规则（.gitignore 文件）git check-ref-format检查引用名称格式是否合法，不合法时返回非零状态码git cat-file查看 Git 仓库对象的内容或类型和大小信息git count-objects统计未打包对象数量及其磁盘占用情况git commit-graph生成和验证 Git 提交图文件git commit-tree用于创建提交对象的底层工具git column以列格式显示数据
