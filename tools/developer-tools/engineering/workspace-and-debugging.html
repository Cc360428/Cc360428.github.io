编辑器与IDE上手与对象

工作区、编辑器配置与调试 ​

确定工作区、搜索与文件编码 ​

需能阅读 Python、JSON 和文件路径。以求和工作区为例，先打开包含 total.py 与 input.json 的目录，再对照 tasks/launch 的参数与 cwd；程序依赖 Python 3.11+，调试另需 VS Code Python Debugger 扩展。 示例未在本轮执行。

IDE 工作区根目录 ​

IDE工作区根目录决定相对路径、搜索范围和任务的工作目录。打开单文件与打开项目的行为不同；多根工作区应明确每个根的职责，避免格式化、索引或任务误扫输出目录。

IDE 导航与搜索 ​

IDE导航应区分文本搜索和符号搜索。前者找字面内容，后者依赖语言分析定位定义及引用；重命名符号应检查引用预览，注释、字符串与动态引用不一定能自动更新。

IDE 编码与换行 ​

IDE编码与换行是文件字节约定：UTF-8解释字符，LF或CRLF分隔行。状态栏显示的编码不证明历史文件解码正确；保存前检查中文和差异，避免整文件换行变化掩盖功能修改。

配置任务、调试与设置作用域 ​

IDE 配置作用域 ​

IDE配置作用域分用户与工作区，提交工作区配置只放团队共识。机器安装路径和个人字体不写共享配置；EditorConfig可统一缩进与末尾换行，但需确认编辑器支持。

IDE tasks.json ​

IDE的tasks.json描述进程、参数与cwd。process类型将参数分开传递，避免Shell转义混淆；workspaceFolder变量根据工作区展开，任务运行目录与当前编辑文件所在目录不必一致。

IDE launch.json ​

IDE的launch.json描述程序入口和调试会话。断点需要源码与实际执行文件对应；Python调试适配器是额外依赖，配置可读不表示已安装或已验证适配器。

排查断点、格式化与快捷键 ​

IDE 断点未命中 ​

IDE断点未命中先核对解释器、入口与当前源码。灰色断点可能尚未绑定到加载模块；路径映射、生成代码和子进程需分别判断，不以重装全部插件作为第一步。

IDE 格式化冲突 ​

IDE格式化冲突常来自保存格式化、语言默认格式器和独立lint修复同时生效。先确定唯一格式器，再用一个文件查看差异；团队规则优先由仓库配置表达，避免提交个人设置。

IDE 快捷键差异 ​

IDE快捷键差异受操作系统、键位方案和焦点控件影响。旧IDEA或VS Code按键表应作为历史参考；用动作名称查找当前绑定，再确认终端是否截获按键。

两份 IDEA 快捷键表的统一使用方式 ​

IDEA 快捷键两份表冲突如何处理？旧 IDEA 表覆盖编辑、导航、搜索、重构与调试，但若按键冲突，应在当前 Keymap 以动作名查绑定，核对操作系统、焦点与插件；以下仅保留历史 Windows 键位线索。原表把 Ctrl+Shift+Space 同时说成参数信息/补全、把 Alt+F10 说成恢复执行、把 Ctrl+Alt+N 说成创建匿名类，这些未经核验的对应关系撤回，不能照表当现行事实。

编辑线索：Ctrl+X/C/V 剪切复制粘贴，Ctrl+Z 与 Ctrl+Shift+Z 撤销/重做，Ctrl+D 复制行，Ctrl+Delete/Backspace 按词删除，Ctrl+Shift+Up/Down 移动代码。Ctrl+/ 与 Ctrl+Shift+/ 注释，Ctrl+Alt+L 格式化，Ctrl+Alt+O 优化导入；先预览改动，避免把整文件格式差异带入业务提交。

导航和搜索线索：Ctrl+N 查类，Ctrl+Shift+N 查文件，Ctrl+Alt+Shift+N 查符号，Ctrl+F12 看结构，Ctrl+E 看最近文件，Ctrl+G 到行，Ctrl+B 到声明，Ctrl+H 看类型层次，Ctrl+Q 看文档。Ctrl+F/R 处理当前文本，Ctrl+Shift+F/R 扩大搜索/替换范围；文本替换不会理解符号引用。

IDEA 代码模板多选重命名有哪些历史线索？代码线索：Alt+Enter 查询意图/快速修复，Alt+Insert 生成成员，Ctrl+Space 补全，Ctrl+Shift+Enter 补全语句，Ctrl+Alt+Space 类名或接口名补全（这些旧动作线索均需核对实际Keymap），Ctrl+P 参数提示，Ctrl+J 代码模板，模板后 Tab 展开。Ctrl+Alt+V 提取变量，Ctrl+Alt+T 包围代码，Shift+F6 重命名；重构先审阅引用预览。Ctrl+W 扩大选择，Alt+F3 逐项选择同文，Ctrl+Shift+F7 高亮用法，Esc 退出高亮。

定位线索：Alt+F1 定位文件，Alt+1 工程面板，Ctrl+Alt+Left/Right 返回浏览位置，Alt+Left/Right 切换视图，Alt+Up/Down 移动方法，F2/Shift+F2 找问题。原表 Alt+Shift+C、Ctrl+Up/Down 与重构菜单组合存在语义不明或配置差异，保留动作需求而撤下绝对按键结论。

调试先区分 Step Over、Step Into、Smart Step Into、Step Out、Run to Cursor、Resume 和断点管理；旧线索 F8、F7、Shift+F7、Shift+F8、Alt+F9、Ctrl+Shift+F8 应逐项在 Keymap 确认。断点执行状态还取决于当前线程和加载源码，快捷键响应不等于目标代码已执行。本次没有打开 IDE 验证键位。

撤回旧 JetBrains 激活操作 ​

旧 IDEA 激活方法为何撤回？旧激活页只剩归档说明：来源为 Java Agent 配置、下载 JAR 与多组激活字符串，缺少可靠版本和有效性证据。该页的“方法一/方法二、IDEA、GoLand、通用”旧锚点均表示已撤回的操作，不存在等价现行教程。原始字节仅留来源快照追溯，公开正文不重复下载地址、配置步骤或激活字符串。

这不影响编辑、导航或调试知识的学习。遇到授权问题，应先识别产品版本与账号授权状态，再使用产品提供的授权入口；本文未核验当前许可政策，也未进行任何激活。快捷键和工作区问题回到本课相应章节，不把授权绕过当成 IDE 排错。
