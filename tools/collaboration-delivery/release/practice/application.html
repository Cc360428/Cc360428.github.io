制品 摘要练习 ​

题目：README改一个字符但版本仍为1.0.0，摘要是否应相同？

参考答案

字节变化会改变SHA-256；同版本重新发布不同字节会破坏不可变性，应生成新版本或明确未发布草稿。

制品 清理恢复 ​

制品清理恢复只删除读者指定输出目录中的demo.zip与manifest.json，先核对路径和保留需要的摘要记录。示例没有线上状态，不存在远端回滚；删除本地包不能撤回已分发副本。

pack.py ​

python
import hashlib
import json
import sys
import zipfile
from pathlib import Path

def pack(output):
    output.mkdir(parents=True, exist_ok=False)
    source = Path(__file__).parent / "payload" / "README.txt"
    if source.is_symlink() or not source.is_file():
        raise ValueError("payload must be a regular file")
    content = source.read_bytes()
    target = output / "demo.zip"
    with zipfile.ZipFile(target, "x", compression=zipfile.ZIP_DEFLATED) as archive:
        archive.writestr("README.txt", content)
    digest = hashlib.sha256(target.read_bytes()).hexdigest()
    manifest = {"version": "1.0.0", "source": "fictional-offline-course",
                "files": [{"name": target.name, "bytes": target.stat().st_size,
                           "sha256": digest}]}
    with (output / "manifest.json").open("x", encoding="utf-8") as stream:
        json.dump(manifest, stream, indent=2)
        stream.write("\n")
    print("created demo.zip and manifest.json; not published")

if __name__ == "__main__":
    try:
        if len(sys.argv) != 2:
            raise ValueError("usage: python pack.py NEW_OUTPUT_DIRECTORY")
        pack(Path(sys.argv[1]))
    except (ValueError, OSError, zipfile.BadZipFile) as exc:
        print(str(exc), file=sys.stderr)
        sys.exit(2)
