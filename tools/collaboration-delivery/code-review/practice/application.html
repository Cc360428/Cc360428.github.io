下列文件与仓库同源，包含完整实现和输入；不是运行证明。部分练习只需人工阅读配置，不强制构造模拟器。

before.py ​

python
def average(values):
    return sum(values) / len(values)

after.py ​

python
def average(values):
    if not values:
        return None
    return sum(values) / len(values)

markdown
# Review of a local candidate (not an external PR)
Contract: list of finite numbers; return arithmetic mean, or None for an empty list.
Finding: before.py divides by len([]), causing ZeroDivisionError for empty input.
Fix: after.py handles empty list before division. [0] is a nonempty list, so
its mean remains 0.0; the guard must not inspect sum(values) for truthiness.
Static trace: [] -> None; [2,4] -> 6/2; [0] -> 0/1.
Not executed. Neither implementation validates element types or finiteness.
Review status: candidate addresses the defined empty-list case only.
