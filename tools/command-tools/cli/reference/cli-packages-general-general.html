包管理、字体与环境工具命令 ​

读取、查看与检索 ​

fc-list · 列出系统上安装的可用字体 ​

更多信息：https://manned.org/fc-list。

  • 返回系统中已安装字体的列表：
bash
fc-list
  • 返回具有给定名称的已安装字体的列表：
bash
fc-list | grep '{{DejaVu Serif}}'
  • 返回系统中已安装字体的数量：
bash
fc-list | wc {{[-l|--lines]}}
  • 返回支持指定语言（基于区域设置代码）的已安装字体列表：
bash
fc-list :lang={{ja}}
  • 返回包含指定 Unicode 码位字形的已安装字体列表：
bash
fc-list :charset={{f303}}

检查状态与定位问题 ​

conda list · 列出一个 conda 环境中已安装的包 ​

更多信息：https://docs.conda.io/projects/conda/en/stable/commands/list.html。

  • 列出当前环境中的所有包：
bash
conda list
  • 列出指定环境的包：
bash
conda list {{[-n|--name]}} {{环境名称}}
  • 列出特定路径下安装的包：
bash
conda list {{[-p|--prefix]}} {{路径/到/环境}}
  • 用 正则表达式 过滤安装的包：
bash
conda list {{正则表达式}}
  • 保存包列表，以供以后使用：
bash
conda list {{[-e|--export]}} > {{路径/到/包列表.txt}}

环境、会话与自动执行 ​

conda · 为任何编程语言准备的包、依赖和环境管理工具 ​

部分子命令（例如 create）有自己的文档。 另请参阅：mamba。 更多信息：https://docs.conda.io/projects/conda/en/latest/commands/index.html。

  • 创建新的环境，并将指定包安装入该环境：
bash
conda create {{[-n|--name]}} {{环境_名称}} {{python=3.9 matplotlib}}
  • 列出所有环境：
bash
conda info {{[-e|--envs]}}
  • 激活某个环境：
bash
conda activate {{环境_名称}}
  • 取消激活某个环境：
bash
conda deactivate
  • 删除一个环境（会移除所有的包）：
bash
conda remove {{[-n|--name]}} {{环境_名称}} --all
  • 将多个包安装到当前环境：
bash
conda install {{python=3.4 numpy}}
  • 列出当前环境中的已安装包：

参见 conda list。

  • 删除未使用的包和缓存：
bash
conda clean {{[-a|--all]}}

direnv · Shell 扩展为加载和卸载环境变量，具体取决于当前目录 ​

更多信息：https://github.com/direnv/direnv/blob/master/man/direnv.1.md。

  • 授予 direnv 当前目录中加载 .envrc：
bash
direnv allow {{.}}
  • 撤销在当前目录加载 .envrc 的授权：
bash
direnv deny {{.}}
  • 使用默认编辑器编辑 .envrc 并在退出时重载环境：
bash
direnv edit {{.}}
  • 触发环境重载：
bash
direnv reload
  • 打印一些调试状态信息：
bash
direnv status

专用工具与其他操作 ​

, · 无需安装即可运行命令 ​

更多信息：https://github.com/nix-community/comma。

  • 运行命令：
bash
, {{命令 -带 -参数}}
  • 将命令添加到子 shell 中：
bash
, {{[-s|--shell]}} {{命令}}
  • 清除缓存：
bash
, {{[-e|--empty-cache]}}

apm · Atom 编辑器的包管理工具 ​

另请参阅：atom。 更多信息：https://github.com/atom/apm。

  • 下载包：http://atom.io/packages 和主题 http://atom.io/themes：
bash
apm install {{包名}}
  • 移除包 / 主题：
bash
apm remove {{包名}}
  • 升级包 / 主题：
bash
apm upgrade {{包名}}

bower · 前端 web 开发的包管理优化工具 ​

一个包可以是 GitHub 中 user/repo 的缩写，一个 Git 端口，一个 URL 链接或者一个已注册的包。 更多信息：https://bower.io/#getting-started。

  • 安装列在项目下 的 bower.json 文件中的依赖：
bash
bower install
  • 安装一个或者多个依赖到 bower_components 目录：
bash
bower install {{包名1 包名2 ...}}
  • 从本地的 bower_components 目录卸载依赖：
bash
bower uninstall {{包名1 包名2 ...}}
  • 列出本地包和可能的更新项：
bash
bower list
  • 创建你的项目的 bower.json：
bash
bower init
  • 安装时候指定依赖的版本号，并添加到 bower.json：
bash
bower install {{local_name}}={{package}}#{{version}} --save
  • 显示 bower 指令的帮助信息：
bash
bower help {{指令}}

eim · 安装和管理 ESP-IDF ​

更多信息：https://docs.espressif.com/projects/idf-im-ui/en/latest/cli_commands.html。

  • 在默认位置（Windows 上为 C:\esp，POSIX 系统上为 ~/.espressif）安装默认（最新）的 ESP-IDF 版本：
bash
eim install
  • 非交互式安装特定 ESP-IDF 版本：
bash
eim install {{[-i|--idf-versions]}} {{v5.3.2}}
  • 运行交互式、指导性的安装向导：
bash
eim wizard
  • 安装特定版本到自定义路径，并强制进入交互模式（以提示选择）：
bash
eim install {{[-i|--idf-versions]}} {{v5.3.2}} {{[-p|--path]}} {{/opt/esp-idf}} {{[-n|--non-interactive]}} false
  • 列出所有当前已安装的 ESP-IDF 版本：
bash
eim list
  • 移除一个特定已安装的 ESP-IDF 版本：
bash
eim remove {{v5.3.2}}
  • 使用 TOML 配置文件中定义的所有选项以无头模式安装：
bash
eim install {{[-c|--config]}} {{path/to/config.toml}}
  • 使用预先下载的归档文件进行离线安装：
bash
eim install --use-local-archive {{path/to/archive.zst}}

nixpkgs-review · 用于审查 NixOS 软件包仓库（nixpkgs）中的拉取请求 ​

构建成功后，会启动包含所有已构建软件包的 nix-shell 环境。 更多信息：https://github.com/Mic92/nixpkgs-review#usage。

  • 构建指定拉取请求中更改的软件包：
bash
nixpkgs-review pr {{pr_number|pr_url}}
  • 构建更改的软件包并发布带报告的评论（需在 hub、gh 或 $GITHUB_TOKEN 环境变量中配置令牌）：
bash
nixpkgs-review pr --post-result {{pr_number|pr_url}}
  • 构建更改的软件包并打印报告：
bash
nixpkgs-review pr --print-result {{pr_number|pr_url}}
  • 构建本地提交中更改的软件包：
bash
nixpkgs-review rev {{HEAD}}
  • 构建尚未提交的更改包：
bash
nixpkgs-review wip
  • 构建已暂存的更改包：
bash
nixpkgs-review wip --staged

upt · 统一的界面，用于管理各种操作系统上的软件包，例如 Windows、许多 Linux 发行版、macOS、FreeBSD，甚至 Haiku ​

它需要安装本机操作系统的软件包管理器。 另请参阅：flatpak, brew, scoop, apt, dnf。 更多信息：https://github.com/sigoden/upt。

  • 更新可用软件包的列表：
bash
upt update
  • 搜索指定的软件包：
bash
upt search {{搜索软件包关键词}}
  • 显示某个软件包的信息：
bash
upt info {{软件包}}
  • 安装指定的软件包：
bash
upt install {{软件包}}
  • 移除指定的软件包：
bash
upt {{remove|uninstall}} {{软件包}}
  • 升级所有已安装的软件包：
bash
upt upgrade
  • 升级指定的软件包：
bash
upt upgrade {{软件包}}
  • 列出已安装的软件包：
bash
upt list

x · 用于管理模块和软件包 ​

更多信息：https://x-cmd.com。

  • 使用特定模块（例如 path 模块）：
bash
x {{module}}
  • 全局安装一个软件包（例如 jq）：
bash
x env use {{package}}
  • 在当前 Shell 会话中临时尝试软件包：
bash
x env try {{package}}
  • 无需安装直接使用软件包：
bash
x {{package}}
  • 初始化 OpenAI API 密钥以使用 AI 功能：
bash
x openai init
  • 查询包的安装方法并执行：
bash
x install

ya · 管理 Yazi 软件包和插件 ​

更多信息：https://yazi-rs.github.io/docs/cli/。

  • 添加一个软件包：
bash
ya pack -a {{软件包}}
  • 升级所有软件包：
bash
ya pack -u
  • 订阅来自所有远程实例的消息：
bash
ya sub {{种类}}
  • 向当前实例发布一个字符串内容的消息：
bash
ya pub --str {{字符串消息}}
  • 向当前实例发布一个 JSON 内容的消息：
bash
ya pub --json {{json消息}}
  • 向指定实例发布一个字符串内容的消息：
bash
ya pub-to --str {{消息}} {{接收者}} {{种类}}

示例整理自 tldr-pages，作者为 tldr-pages team and contributors，遵循 CC BY 4.0。
