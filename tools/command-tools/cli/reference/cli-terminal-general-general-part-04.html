检查主机状态与调整终端 ​

uname、hostname 和 uptime 提供主机信息；终端显示与输入选项见 clear、stty，exit 结束当前会话。

uname · 输出关于当前机器和运行在该机器上的操作系统的详细信息 ​

另请参阅：lsb_release。 更多信息：https://www.gnu.org/software/coreutils/manual/html_node/uname-invocation.html。

  • 打印内核名称：
bash
uname
  • 打印所有可用的系统信息：
bash
uname {{[-a|--all]}}
  • 打印系统架构和处理器信息：
bash
uname {{[-mp|--machine --processor]}}
  • 打印内核名称、内核版本号和内核版本：
bash
uname {{[-srv|--kernel-name --kernel-release --kernel-version]}}
  • 打印系统主机名：
bash
uname {{[-n|--nodename]}}
  • 打印当前操作系统名称：
bash
uname {{[-o|--operating-system]}}
  • 打印当前网络节点主机名：
bash
uname {{[-n|--nodename]}}
  • 显示帮助：
bash
uname --help

hostname · 显示或设置系统的主机名 ​

更多信息：https://www.gnu.org/software/inetutils/manual/inetutils.html#hostname-invocation。

  • 显示本机的主机名：
bash
hostname
  • 显示主机名的网络地址：
bash
hostname {{[-i|--ip-address]}}
  • 显示 FQDN（完全限定域名）：
bash
hostname {{[-f|--fqdn]}}
  • 设置本机主机名：
bash
hostname {{新主机名}}

uptime · 告知当前系统运行多长时间和其他信息 ​

更多信息：https://www.gnu.org/software/coreutils/manual/html_node/uptime-invocation.html。

  • 打印当前时间，运行时间，登录用户数量和其他信息：
bash
uptime
  • 仅显示系统已启动的时间长度：
bash
uptime {{[-p|--pretty]}}
  • 打印系统启动的日期和时间：
bash
uptime {{[-s|--since]}}
  • 显示版本信息：
bash
uptime {{[-V|--version]}}

clear · 清空终端的屏幕 ​

更多信息：https://manned.org/clear。

  • 清空屏幕（相当于在 Bash shell 中按 <Ctrl l> 键）：
bash
clear
  • 清空屏幕但保留终端的回滚缓冲区：
bash
clear -x
  • 指明要清空的终端类型（默认为环境变量 $TERM 的值）：
bash
clear -T {{type_of_terminal}}
  • 显示 clear 使用的 ncurses 版本：
bash
clear -V

stty · 设置终端设备接口的选项 ​

另请参阅：tput。 更多信息：https://www.gnu.org/software/coreutils/manual/html_node/stty-invocation.html。

  • 显示当前终端的所有设置：
bash
stty {{[-a|--all]}}
  • 设置行数或列数：
bash
stty {{rows|cols}} {{数量}}
  • 获取设备的实际传输速度：
bash
stty {{[-F|--file]}} {{路径/到/设备文件}} speed
  • 重置所有模式为当前终端的合理默认值：
bash
stty sane
  • 在原始模式和普通模式之间切换：
bash
stty {{raw|cooked}}
  • 关闭或开启字符回显：
bash
stty {{-echo|echo}}
  • 显示帮助：
bash
stty --help

exit · 退出终端程序 ​

更多信息：https://manned.org/exit.1posix。

  • 使用最后执行命令的退出代码，退出终端程序：
bash
exit
  • 使用指定的退出代码，退出终端程序：
bash
exit {{exit_code}}

] · 这个 shell 关键字用于结束 [ ​

闭合方括号 ] 与 [ 配对；条件判断及文件测试见 test 与方括号。

]] · 这个 shell 关键字用于结束 [[ ​

闭合双方括号 ]] 与 [[ 配对；模式匹配及数值比较见 Bash 双方括号。

阅读差异与管理开发平台 ​

delta 查看差异；FastAPI、Heroku 和 JFrog 条目分别保留应用启动和平台管理示例。

delta · Git 和 diff 输出的查看器 ​

另请参阅：diff, difft。 更多信息：https://dandavison.github.io/delta/full---help-output.html。

  • 比较文件或目录：
bash
delta {{路径/到/旧文件或目录}} {{路径/到/新文件或目录}}
  • 比较文件或目录，显示行号：
bash
delta {{[-n|--line-numbers]}} {{路径/到/旧文件或目录}} {{路径/到/新文件或目录}}
  • 比较文件或目录，并排显示差异：
bash
delta {{[-s|--side-by-side]}} {{路径/到/旧文件或目录}} {{路径/到/新文件或目录}}
  • 比较文件或目录，忽略任何 Git 配置设置：
bash
delta --no-gitconfig {{路径/到/旧文件或目录}} {{路径/到/新文件或目录}}
  • 比较，根据终端模拟器的超链接规范，将提交哈希、文件名和行号渲染为超链接：
bash
delta --hyperlinks {{路径/到/旧文件或目录}} {{路径/到/新文件或目录}}
  • 显示当前设置：
bash
delta --show-config
  • 显示支持的语言及相关文件扩展名：
bash
delta --list-languages

fastapi · 运行 FastAPI 应用的命令行工具，底层使用 Uvicorn ​

更多信息：https://manned.org/fastapi。

  • 使用自动重载运行 FastAPI 应用（用于开发）：
bash
fastapi run {{路径/文件.py}} --reload
  • 在开发模式下运行应用：
bash
fastapi dev {{路径/文件.py}}
  • 指定运行的主机和端口：
bash
fastapi run {{路径/文件.py}} --host {{主机地址}} --port {{端口}}
  • 设置应用变量名（如果不是 app）或指定自定义应用目录：
bash
fastapi run {{路径/文件.py}} --app-dir {{路径/到/应用}} --app {{自定义_app_名称}}
  • 显示帮助：
bash
fastapi --help
  • 显示子命令的帮助信息：
bash
fastapi {{子命令}} --help

heroku · 从命令行创建和管理 Heroku 应用 ​

更多信息：https://devcenter.heroku.com/articles/heroku-cli#get-started-with-the-heroku-cli。

  • 登录到你的 heroku 帐户：
bash
heroku login
  • 创建一个 heroku 应用：
bash
heroku create
  • 显示应用的日志：
bash
heroku logs --app {{app_name}}
  • 在 dyno（Heroku 虚拟机）中运行一次性进程：
bash
heroku run {{process_name}} --app {{app_name}}
  • 列出应用的 dyno（Heroku 虚拟机）：
bash
heroku ps --app {{app_name}}
  • 永久销毁应用：
bash
heroku destroy --app {{app_name}}

jf · 与 JFrog 产品进行交互，比如 Artifactory、Xray、Distribution、Pipelines 和 Mission Control ​

更多信息：https://jfrog.com/help/r/jfrog-applications-and-cli-documentation/jfrog-cli。

  • 添加一个新配置：
bash
jf config add
  • 显示当前配置：
bash
jf config show
  • 在给定的仓库和目录中搜索制品：
bash
jf rt search --recursive {{仓库名称}}/{{路径}}/

计算、日历、书签与日记 ​

计算工具按 qalc、yacas、MATLAB 查阅；日历、书签和日记分别放在 jcal、buku、jrnl。

qalc · 强大且易用的命令行计算器 ​

另请参阅：bc。 更多信息：https://qalculate.github.io/manual/qalc.html。

  • 以交互模式启动：
bash
qalc {{[-i|--interactive]}}
  • 以简洁模式启动（仅输出结果）：
bash
qalc {{[-t|--terse]}}
  • 更新货币兑换率：
bash
qalc {{[-e|--exrates]}}
  • 非交互地执行计算：
bash
qalc {{66+99|2^4|6 feet to cm|1 bitcoin to USD|20 kmph to mph|...}}
  • 列出所有支持的函数/前缀/单位/变量：
bash
qalc --{{list-functions|list-prefixes|list-units|list-variables}}
  • 从文件中执行命令：
bash
qalc {{[-f|--file]}} {{路径/到/文件}}

yacas · 另一个计算机代数系统 ​

更多信息：https://www.yacas.org/。

  • 启动交互式的 yacas 会话：
bash
yacas
  • 在 yacas 会话中，执行一个语句：
bash
{{Integrate(x)Cos(x)}};
  • 在 yacas 会话中，显示一个示例：
bash
Example();
  • 从 yacas 会话中退出：
bash
quit
  • 执行一个或多个 yacas 脚本（没有终端或提示符），然后退出：
bash
yacas -p -c {{路径/到/脚本1 路径/到/脚本2 ...}}
  • 执行并打印一个语句的结果，然后退出：
bash
echo "{{Echo( Deriv(x)Cos(1/x) );}}" | yacas -p -c /dev/stdin

matlab · MathWorks 制作的数值计算环境 ​

更多信息：https://www.mathworks.com/help/matlab/matlab_env/startup-options/。

  • 在启动过程中，运行时不出现闪屏：
bash
matlab -nosplash
  • 执行 MATLAB 语句：
bash
matlab -r "{{matlab_语句}}"
  • 运行 MATLAB 脚本：
bash
matlab -r "run({{路径/script.m}})"

jcal · 以贾拉里历格式显示日历信息，并突出显示当前日期 ​

更多信息：https://www.nongnu.org/jcal/jcal.html。

  • 显示当前月份的日历：
bash
jcal
  • 显示上个月、当前月份和下个月的日历：
bash
jcal -3
  • 显示特定年份（4 位数字） 的日历：
bash
jcal {{年份}}
  • 显示特定年份和月份的日历：
bash
jcal {{年份}} {{月份}}

buku · 命令行版本的书签管理器 ​

更多信息：https://github.com/jarun/Buku#usage。

  • 根据关键词和标签“隐私”查找书签：
bash
buku {{关键词}} {{[-t|--stag]}} {{隐私}}
  • 添加书签，并且打上标签“搜索引擎”和“隐私”：
bash
buku {{[-a|--add]}} {{https://example.com}} {{搜索引擎}}, {{隐私}}
  • 删除一个书签：
bash
buku {{[-d|--delete]}} {{书签 id}}
  • 打开编辑器，修改书签：
bash
buku {{[-w|--write]}} {{书签 id}}
  • 移除一个书签中的标签“搜索引擎”：
bash
buku {{[-u|--update]}} {{书签 id}} --tag - {{搜索引擎}}

jrnl · 一个简单的命令行日记应用程序 ​

更多信息：https://jrnl.sh/en/stable/reference-command-line/。

  • 使用编辑器插入一个新条目：
bash
jrnl
  • 快速插入一个新条目：
bash
jrnl {{today at 3am}}: {{标题}}. {{内容}}
  • 查看最近的十条条目：
bash
jrnl -n {{10}}
  • 查看从去年开始到今年三月初所有发生的事情：
bash
jrnl -from "{{last year}}" -until {{march}}
  • 编辑所有用 "texas" 和 "history" 标签标记的条目：
bash
jrnl {{@texas}} -and {{@history}} --edit

whois · WHOIS（RFC 3912）协议的命令行客户端 ​

更多信息：https://manned.org/whois。

  • 获取域名信息：
bash
whois {{example.com}}
  • 获取 IP 地址信息：
bash
whois {{8.8.8.8}}
  • 获取 IP 地址用于报告滥用的联系方式：
bash
whois -b {{8.8.8.8}}
