命令与脚本：进程、服务与资源 · 启动、监督与切换服务至启动监控组件与检查专用工具 ​

启动、监督与切换服务 ​

PM2 和 runit 是不同的服务管理路径；runit 相关命令放在一起，按服务目录监督、单服务控制和目录切换查阅。

pm2 · Node.js 的进程管理工具 ​

用于日志管理、监控和配置进程。 更多信息：https://pm2.keymetrics.io/docs/usage/quick-start/。

  • 启动一个进程并指定名称，以便后续操作使用：
bash
pm2 start {{app.js}} --name {{应用名称}}
  • 列出所有进程：
bash
pm2 list
  • 监控所有进程：
bash
pm2 monit
  • 停止一个进程：
bash
pm2 stop {{应用名称}}
  • 重启一个进程：
bash
pm2 restart {{应用名称}}
  • 保存当前所有进程，便于稍后恢复：
bash
pm2 save
  • 恢复之前保存的进程：
bash
pm2 resurrect

runit · 三级初始化系统 ​

更多信息：https://smarden.org/runit/runit.8。

  • 启动 runit 的三阶段初始化方案：
bash
runit
  • 在 runit 的阶段 2 请求进入系统关机阶段（仅当 /etc/runit/stopit 存在且所有者有执行权限时；不是停止普通服务）：
bash
kill --CONT {{runit 进程 id}}

runsvdir · 运行整个目录下的服务 ​

更多信息：https://manned.org/runsvdir。

  • 以当前用户身份启动和管理目录中的所有服务：
bash
runsvdir {{路径/到/服务目录}}
  • 以 root 用户身份启动和管理目录中的所有服务：
bash
sudo runsvdir {{路径/到/服务目录}}
  • 在单独会话中启动服务：
bash
runsvdir -P {{路径/到/服务目录}}

runsv · 启动和管理 runit 服务 ​

更多信息：https://manned.org/runsv。

  • 以当前用户身份启动 runit 服务：
bash
runsv {{路径/到/服务目录}}
  • 以 root 用户身份启动 runit 服务：
bash
sudo runsv {{路径/到/服务目录}}

sv · 控制一个正在运行的 runsv 服务 ​

更多信息：https://manned.org/sv。

  • 启动服务：
bash
sudo sv up {{路径/到/服务目录}}
  • 停止服务：
bash
sudo sv down {{路径/到/服务目录}}
  • 获取服务状态：
bash
sudo sv status {{路径/到/服务目录}}
  • 重载服务：
bash
sudo sv reload {{路径/到/服务目录}}
  • 启动服务，但仅当它未运行时启动，停止后不自动重启：
bash
sudo sv once {{路径/到/服务目录}}

runsvchdir · 更改默认使用的 runsvdir 目录 ​

更多信息：https://manned.org/runsvchdir。

  • 切换 runsvdir 目录：
bash
sudo runsvchdir {{路径/到/目录}}

bird · BIRD 互联网路由守护程序 ​

支持 BGP、OSPF、Babel 等协议的路由守护进程。 更多信息：https://bird.network.cz/?get_doc&v=30&f=bird-1.html#ss1.3。

  • 使用特定配置文件启动 Bird：
bash
bird -c {{路径/到/bird.conf}}
  • 以特定用户和组身份启动 Bird：
bash
bird -u {{用户名}} -g {{组}}

zerotier-one · 启动 ZeroTier One 守护进程 ​

另请参阅：zerotier-cli, zerotier-idtool。 更多信息：https://github.com/zerotier/ZeroTierOne/blob/main/doc/zerotier-one.8.md。

  • 启动 ZeroTier One [d] 守护进程：
bash
sudo zerotier-one -d

启动监控组件与检查专用工具 ​

Zabbix 服务端与两种 agent 相邻；其他条目分别处理系统概览、APK 资源、模型任务和 ZFS 调试。

zabbix_server · Zabbix 软件的核心守护进程 ​

更多信息：https://manned.org/zabbix_server。

  • 使用默认配置文件启动服务器：
bash
zabbix_server
  • 使用自定义配置文件启动服务器：
bash
zabbix_server {{[-c|--config]}} {{路径/到/zabbix_server.conf}}
  • 在前台运行服务器：
bash
zabbix_server {{[-c|--config]}} {{路径/到/zabbix_server.conf}} {{[-f|--foreground]}}
  • 测试配置文件并退出：
bash
zabbix_server {{[-c|--config]}} {{路径/到/zabbix_server.conf}} {{[-T|--test-config]}}
  • 重新加载配置缓存（运行时控制）：
bash
zabbix_server {{[-c|--config]}} {{路径/到/zabbix_server.conf}} {{[-R|--runtime-control]}} config_cache_reload
  • 执行 housekeeper（运行时控制）：
bash
zabbix_server {{[-c|--config]}} {{路径/到/zabbix_server.conf}} {{[-R|--runtime-control]}} housekeeper_execute
  • 增加或减少所有进程的日志级别（运行时控制）：
bash
zabbix_server {{[-c|--config]}} {{路径/到/zabbix_server.conf}} {{[-R|--runtime-control]}} log_level_{{increase|decrease}}
  • 显示帮助：
bash
zabbix_server {{[-h|--help]}}

zabbix_agentd · 用于监控服务器参数的守护进程 ​

更多信息：https://manned.org/zabbix_agentd。

  • 使用默认配置文件启动 agent：
bash
zabbix_agentd
  • 使用自定义配置文件启动 agent：
bash
zabbix_agentd {{[-c|--config]}} {{路径/到/zabbix_agentd.conf}}
  • 在前台运行 agent（保持附着在当前终端会话中）：
bash
zabbix_agentd {{[-c|--config]}} {{路径/到/zabbix_agentd.conf}} {{[-f|--foreground]}}
  • 测试配置文件：
bash
zabbix_agentd {{[-c|--config]}} {{路径/到/zabbix_agentd.conf}} {{[-T|--test-config]}}
  • 使用详细输出测试指定的监控项：
bash
zabbix_agentd {{[-c|--config]}} {{路径/到/zabbix_agentd.conf}} {{[-t|--test]}} {{监控项键值}} {{[-v|--verbose]}}
  • 从配置文件重新加载用户参数（运行时控制）：
bash
zabbix_agentd {{[-c|--config]}} {{路径/到/zabbix_agentd.conf}} {{[-R|--runtime-control]}} userparameter_reload
  • 提高或降低所有进程的日志级别（运行时控制）：
bash
zabbix_agentd {{[-c|--config]}} {{路径/到/zabbix_agentd.conf}} {{[-R|--runtime-control]}} log_level_{{increase|decrease}}
  • 显示帮助：
bash
zabbix_agentd {{[-h|--help]}}

zabbix_agent2 · 用于监控服务器参数的守护进程 ​

更多信息：https://manned.org/zabbix_agent2。

  • 使用默认配置文件启动代理：
bash
zabbix_agent2
  • 使用自定义配置文件启动代理：
bash
zabbix_agent2 {{[-c|--config]}} {{路径/到/zabbix_agent2.conf}}
  • 测试配置文件并退出：
bash
zabbix_agent2 {{[-c|--config]}} {{路径/到/zabbix_agent2.conf}} {{[-T|--test-config]}}
  • 测试指定监控项并输出详细信息：
bash
zabbix_agent2 {{[-c|--config]}} {{路径/到/zabbix_agent2.conf}} {{[-t|--test]}} {{监控项键值}} {{[-v|--verbose]}}
  • 从配置文件中重新加载用户参数（运行时控制）：
bash
zabbix_agent2 {{[-c|--config]}} {{路径/到/zabbix_agent2.conf}} {{[-R|--runtime-control]}} userparameter_reload
  • 增加或减少日志级别（运行时控制）：
bash
zabbix_agent2 {{[-c|--config]}} {{路径/到/zabbix_agent2.conf}} {{[-R|--runtime-control]}} loglevel {{increase|decrease}}
  • 显示帮助：
bash
zabbix_agent2 {{[-h|--help]}}

neofetch · 命令行系统信息工具，以美观的方式显示系统信息 ​

另请参阅：fastfetch。 更多信息：https://manned.org/neofetch。

  • 显示系统信息：
bash
neofetch
  • 在输出中显示或隐藏指定的信息行，'信息名称'是配置文件中的函数名称，例如 memory：
bash
neofetch --{{enable|disable}} {{信息名称}}
  • 隐藏或显示操作系统架构信息：
bash
neofetch --os_arch {{on|off}}
  • 启用或禁用输出中的 CPU 品牌信息：
bash
neofetch --cpu_brand {{on|off}}

aapt · 安卓资源包工具（Android Asset Packaging Tools） ​

该工具可以查看，创建，更新资源压缩包（zip, jar, apk）。 更多信息：https://manned.org/aapt。

  • 列出资源压缩包里的内容：
bash
aapt list {{路径/到/应用}}.apk
  • 查看 APK 包内指定的内容（版本，权限许可等）：
bash
aapt dump badging {{路径/到/应用}}.apk
  • 打包生成资源压缩包：
bash
aapt package -F {{路径/到/应用}}.apk {{路径/到/目录}}

yolo · YOLO 命令行界面让你可以简单地在不同的任务和版本上进行模型的训练、验证或推理 ​

更多信息：https://docs.ultralytics.com/usage/cli/。

  • 在当前工作目录中创建默认配置的副本：
bash
yolo copy-cfg
  • 使用指定的配置文件训练目标检测、实例分割或分类模型：
bash
yolo task={{detect|segment|classify}} mode=train cfg={{路径/到/config.yaml}}

zdb · ZFS 调试器 ​

更多信息：https://manned.org/zdb。

  • 显示所有已挂载 ZFS 存储池的详细配置：
bash
zdb
  • 显示特定 ZFS 存储池的详细配置：
bash
zdb {{[-C|--config]}} {{存储池名称}}
  • 显示关于块的数量、大小和重复数据删除的统计信息：
bash
zdb {{[-b|--block-stats]}} {{存储池名称}}
