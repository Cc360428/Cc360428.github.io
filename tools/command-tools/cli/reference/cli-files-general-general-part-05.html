块映像、挂载与隔离目录 ​

块文件复制与 MTP 挂载属于设备操作；chroot 改变进程看到的根目录，umount 解除挂载。

bmaptool · 便捷地创建或复制块文件映射（被设计的比cp或dd更快） ​

更多信息：https://manned.org/bmaptool。

  • 从磁盘映像生成块映射文件（不是普通图片）：
bash
bmaptool create {{[-o|--output]}} {{blockmap 格式文件.bmap}} {{磁盘映像.img}}
  • 把磁盘映像写入指定块设备（覆盖设备内容，先确认目标）：
bash
bmaptool copy --bmap {{blockmap 格式文件}} {{磁盘映像.img}} {{/dev/目标设备}}
  • 把压缩磁盘映像写入指定块设备（覆盖设备内容，先确认目标）：
bash
bmaptool copy --bmap {{blockmap 格式文件}} {{磁盘映像.img.gz}} {{/dev/目标设备}}
  • 不使用块映射文件，直接把磁盘映像写入指定块设备：
bash
bmaptool copy --nobmap {{磁盘映像.img}} {{/dev/目标设备}}

jmtpfs · 基于 FUSE 的文件系统，用于访问 MTP 设备 ​

更多信息：https://manned.org/jmtpfs。

  • 将一个 MTP 设备挂载到一个目录：
bash
jmtpfs {{路径/到/目录}}
  • 设置挂载选项：
bash
jmtpfs -o {{allow_other,auto_unmount}} {{路径/到/目录}}
  • 列出可用的 MTP 设备：
bash
jmtpfs {{[-l|--listDevices]}}
  • 如果存在多个设备，挂载一个特定的设备：
bash
jmtpfs -device={{总线_id}},{{设备_id}} {{路径/到/目录}}
  • 卸载 MTP 设备：
bash
fusermount -u {{路径/到/目录}}

umount · 将文件系统与其挂载点解除链接，使其不再可访问 ​

当文件系统正在使用时，无法卸载。 更多信息：https://man.openbsd.org/umount。

  • 卸载文件系统，通过传递挂载源的路径：
bash
umount {{路径/到/设备文件}}
  • 卸载文件系统，通过传递挂载目标的路径：
bash
umount {{路径/到/挂载目录}}
  • 卸载所有已挂载的文件系统（proc 文件系统除外）：
bash
umount -a

chroot · 使用指定的根目录运行命令或交互式 shell ​

更多信息：https://www.gnu.org/software/coreutils/manual/html_node/chroot-invocation.html。

  • 以新的根目录，运行命令：
bash
sudo chroot {{路径/到/新/根目录}} {{命令}}
  • 使用指定的用户和组：
bash
sudo chroot --userspec {{用户名或用户id:组名或组id}} {{路径/到/新/根目录}} {{命令}}

处理包文件、开发资源与命令片段 ​

这些条目面向特定文件格式或开发工作：静态库、APK、字体缓存、Ruby 格式化以及命令片段和剪贴板选择。

ar · 创建、修改和提取归档（常为包含 .o 成员的 .a 静态库，不用于解析 .so） ​

另请参阅：tar。 更多信息：https://manned.org/ar。

  • 从库文件中提取全部成员：
bash
ar x {{a 文件}}
  • 列出库文件中的成员：
bash
ar t {{a 文件}}
  • 替换或添加文件到库文件：
bash
ar r {{要被添加内容的 a 文件}} {{o 文件1 o 文件2 o 文件3 ...}}
  • 插入对象文件索引（相当于使用ranlib）：
bash
ar s {{a 文件}}
  • 使用文件和附带的目标文件索引创建存档：
bash
ar rs {{a 文件}} {{o 文件1 o 文件2 ...}}

afconvert · 在 AFF 和 raw 文件格式之间进行转换 ​

更多信息：https://manned.org/afconvert。

  • 使用一个特定的扩展名（默认：aff）：
bash
afconvert -a {{扩展名}} {{路径/到/输入文件}} {{路径/到/输出文件1 路径/到/输出文件2 ...}}
  • 使用一个特定的压缩级别（默认：7）：
bash
afconvert -X{{0..7}} {{路径/到/输入文件}} {{路径/到/输出文件1 路径/到/输出文件2 ...}}

apktool · APK 文件反编译工具 ​

更多信息：https://ibotpeaches.github.io/Apktool/。

  • 反编译：
bash
apktool d {{应用}}.apk
  • 将一个文件夹打包为 apk 文件：
bash
apktool b {{路径/到/目录}}
  • 安装并存储框架：
bash
apktool if {{框架}}.apk

zipalign · Zip 文件对齐工具 ​

是 Android 软件开发工具包构建工具的一部分。 更多信息：https://developer.android.com/tools/zipalign。

  • 在 4 字节边界上对齐一个 Zip 文件的数据：
bash
zipalign {{4}} {{路径/到/输入.zip}} {{路径/到/输出.zip}}
  • 检查一个 Zip 文件是否在 4 字节边界上正确对齐，并以详细的方式显示结果：
bash
zipalign -v -c {{4}} {{路径/到/输入.zip}}

fc-cache · 扫描字体目录，以便建立字体缓存文件 ​

更多信息：https://manned.org/fc-cache。

  • 生成字体缓存文件：
bash
fc-cache
  • 强制重建所有字体缓存文件，而不检查缓存是否为最新版本：
bash
fc-cache -f
  • 删除字体缓存文件，然后生成新的字体缓存文件：
bash
fc-cache -r

rubocop · 格式化 Ruby 文件 ​

更多信息：https://docs.rubocop.org/rubocop/latest/usage/cli_reference.html。

  • 检查当前目录中的所有文件（包括子目录）：
bash
rubocop
  • 检查一个或多个指定文件或目录：
bash
rubocop {{路径/到/文件1 路径/到/文件2 ...}}
  • 将输出写入指定文件：
bash
rubocop --out {{路径/到/文件}}
  • 查看规则列表（格式化规则）：
bash
rubocop --show-cops
  • 排除格式规则：
bash
rubocop --except {{规则 1 规则 2 ...}}
  • 只运行指定的规则：
bash
rubocop --only {{规则 1 规则 2 ...}}
  • 自动更正文件（实验）：
bash
rubocop --auto-correct

etcd · 分布式，可靠的键值存储，用于分布式系统中存储最关键的数据 ​

更多信息：https://etcd.io/docs/latest/op-guide/configuration/#command-line-flags。

  • 启动单节点 etcd 集群：
bash
etcd
  • 启动一个单节点 etcd 集群，在自定义 URL 上侦听客户端请求：
bash
etcd --advertise-client-urls {{http://127.0.0.1:1234}} --listen-client-urls {{http://127.0.0.1:1234}}
  • 使用自定义名称启动单节点 etcd 集群：
bash
etcd --name {{my_etcd_cluster}}
  • 启动单节点 etcd 并开启性能剖析；/debug/pprof/ 是剖析入口，监控指标位于客户端端口的 /metrics（实际监听地址以配置为准）：
bash
etcd --enable-pprof --metrics extensive

qc · 管理和执行存储在 QOwnNotes 笔记中的命令片段 ​

另请参阅：qownnotes。 更多信息：https://www.qownnotes.org/getting-started/command-line-snippet-manager.html。

  • 配置代码片段管理器，例如设置来自 QOwnNotes 的安全令牌：
bash
qc configure
  • 搜索并打印存储在 Commands.md 笔记中的命令片段以及所有标记为 commands 的笔记：
bash
qc search
  • 执行一个片段并在执行前显示命令：
bash
qc exec --command
  • 执行上一个片段并在执行前显示命令：
bash
qc exec --command --last
  • 在 QOwnNotes 中切换笔记文件夹：
bash
qc switch

yank · 从 stdin 读取输入并显示一个选择界面，该界面允许选择一个字段并将其复制到剪贴板 ​

更多信息：https://manned.org/yank。

  • 使用默认分隔符（\f, \n, \r, \s, \t）：
bash
{{sudo dmesg}} | yank
  • 输入单行：
bash
{{sudo dmesg}} | yank -l
  • 使用特定分 = 隔符输入：
bash
{{echo hello=world}} | yank -d {{=}}
  • 只有与特定正则表达式匹配的内容才输入：
bash
{{ps ux}} | yank -g "{{[0-9]+}}"
