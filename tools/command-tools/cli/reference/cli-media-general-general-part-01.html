命令与脚本：图片、音视频与文档 ​

检查媒体属性并查看、播放 ​

先确认图像格式和属性，再选择图片、模型或音视频查看器；Markdown 渲染与屏幕亮度作为显示相关工具列在末尾。

magick identify · 输出图片文件的格式与属性 ​

另请参阅：magick。 更多信息：https://imagemagick.org/script/identify.php。

  • 输出图片的格式以及一些基本属性：
bash
magick identify {{路径/到/图片}}
  • 输出图片的格式及其详细属性：
bash
magick identify -verbose {{路径/到/图片}}
  • 将当前目录下的所有 JPEG 图片的尺寸属性：
bash
magick identify -format "{{%f,%w,%h\n}}" {{*.jpg}} > {{路径/到/文件列表.csv}}

feh · 轻量级图像查看工具 ​

更多信息：https://man.finalrewind.org/1/feh/。

  • 查看本地图像或使用 URL：
bash
feh {{路径/到/图像}}
  • 递归查看图像：
bash
feh --recursive {{路径/到/图像}}
  • 使用无边框窗口查看图像：
bash
feh --borderless {{路径/到/图像}}
  • 在浏览完最后一个图像之后退出：
bash
feh --cycle-once {{路径/到/图像}}
  • 设置幻灯片放映周期延迟时间（秒）：
bash
feh --slideshow-delay {{秒}} {{路径/到/图像}}
  • 设置墙纸（居中、填充、最大化、缩放或平铺）：
bash
feh --bg-{{center|fill|max|scale|tile}} {{路径/到/图像}}
  • 创建目录中所有图像的拼贴，并作为新图像输出：
bash
feh --montage --thumb-height {{150}} --thumb-width {{150}} --index-info "{{%nn%wx%h}}" --output {{路径/到/拼贴图像.png}}

imgcat · 直接在命令行上显示图像的实用程序 ​

需要兼容的终端软件，如 iTerm2。 更多信息：https://github.com/danielgatis/imgcat#usage。

  • 在命令行上显示图像：
bash
imgcat {{文件名}}

3d-ascii-viewer · 在终端中以动画 ASCII 的形式查看 3D .obj 模型 ​

更多信息：https://github.com/autopawn/3d-ascii-viewer。

  • 显示一个模型：
bash
3d-ascii-viewer {{路径/到/模型}}.obj
  • 设置宽度和高度：
bash
3d-ascii-viewer -w {{宽度}} -h {{高度}} {{路径/到/模型}}.obj
  • 启用颜色：
bash
3d-ascii-viewer --color {{路径/到/模型}}.obj
  • 设置每秒帧数：
bash
3d-ascii-viewer -f {{每秒帧数}} {{路径/到/模型}}.obj
  • 交互模式：
bash
3d-ascii-viewer --interactive {{路径/到/模型}}.obj
  • 显示帮助：
bash
3d-ascii-viewer --help

mpv · 一个基于 MPlayer 的音频/视频播放器 ​

另请参阅：mplayer, vlc。 更多信息：https://mpv.io/manual/stable/。

  • 从 URL 或文件播放视频或音频：
bash
mpv {{url|路径/到/文件}}
  • 向后/向前跳跃 5 秒：
bash
{{<ArrowLeft>|<ArrowRight>}}
  • 向后/向前跳跃 1 分钟：
bash
{{<ArrowDown>|<ArrowUp>}}
  • 减少/增加 10% 播放速度：
bash
{{<[>|<]>}}
  • 对当前帧截图（默认保存到 ./mpv-shotNNNN.jpg）：
bash
<s>
  • 以指定速度播放文件（0.01 到 100, 默认是 1）：
bash
mpv --speed {{0.01..100}} {{路径/到/文件}}
  • 用 mpv.conf 中指定的一个用户配制播放文件：
bash
mpv --profile {{配置文件名称}} {{路径/到/文件}}
  • 显示来自网络摄像头或其他视频输入设备的输出：
bash
mpv {{/dev/video0}}

vlc · 跨平台多媒体播放器 ​

另请参阅：mpv, mplayer, ytfzf。 更多信息：https://wiki.videolan.org/Documentation:Command_line/。

  • 播放一个文件：
bash
vlc {{文件名}}
  • 全屏播放：
bash
vlc --fullscreen {{文件名}}
  • 静音播放：
bash
vlc --no-audio {{文件名}}
  • 循环播放：
bash
vlc --loop {{文件名}}
  • 播放网络连接：
bash
vlc {{连接}}

qmmp · 具有类似于 Winamp 或 XMMS 界面的音频播放器 ​

另请参阅：clementine, ncmpcpp, cmus。 更多信息：https://manned.org/qmmp。

  • 启动 GUI：
bash
qmmp
  • 开始或停止当前播放的音频：
bash
qmmp {{[-t|--play-pause]}}
  • 向前或向后移动指定的秒数：
bash
qmmp --seek-{{fwd|bwd}} {{秒数}}
  • 播放下一个音频文件：
bash
qmmp --next
  • 播放上一个音频文件：
bash
qmmp --previous
  • 显示当前音量：
bash
qmmp --volume-status
  • 增加或减少当前播放音频的音量 5%：
bash
qmmp --volume-{{inc|dec}}

youtube-viewer · 搜索并播放 YouTube 上的视频 ​

另请参阅：you-get, ytfzf, yt-dlp。 更多信息：https://github.com/trizen/youtube-viewer。

  • 搜索一个视频：
bash
youtube-viewer {{搜索关键词}}
  • 登录到你的 YouTube 账户：
bash
youtube-viewer --login
  • 在 VLC 中观看指定 URL 的视频：
bash
youtube-viewer --player={{vlc}} {{https://youtube.com/watch?v=dQw4w9WgXcQ}}
  • 显示一个搜索提示并以 720p 播放已选视频：
bash
youtube-viewer -{{7}}

glow · 在终端渲染 Markdown ​

更多信息：https://manned.org/glow。

  • 运行 glow 并选择文件查看：
bash
glow
  • 渲染 Markdown 文件到终端：
bash
glow {{路径/到/文件}}
  • 使用分页器查看 Markdown 文件：
bash
glow {{[-p|--pager]}} {{路径/到/文件}}
  • 从 URL 查看文件：
bash
glow {{https://example.com/file.md}}
  • 查看 GitHub 或 GitLab 的 README：
bash
glow {{github.com/owner/repository}}

ybacklight · 管理屏幕背光亮度 ​

另请参阅：xbacklight。 更多信息：https://github.com/pixelcmtd/ybacklight。

  • 打印当前亮度和最大亮度，缩写并使用斜杠分隔：
bash
ybacklight Sc/Sm
  • 指定亮度：
bash
ybacklight s{{420}}
  • 增加 42 个大步的亮度（默认 4200）：
bash
ybacklight Si42
  • 减少 300 的亮度：
bash
ybacklight d300

截图与下载媒体 ​

截图入口是 magick import；网络媒体下载按所用工具选择，ytmdl 还包含歌曲元数据处理。

magick import · 捕获某些或全部 X server 屏幕上的内容，并保存至图片文件当中 ​

另请参阅：magick。 更多信息：https://imagemagick.org/script/import.php。

  • 捕获整个 X server 屏幕，保存为 PostScript 文件：
bash
magick import -window root {{路径/到/输出文件.ps}}
  • 捕获远程 X server 屏幕，保存为 PNG 图片：
bash
magick import -window root -display {{remote_host}}:{{display}}.{{screen}} {{路径/到/输出文件.png}}
  • 用 xwininfo 中列出的窗口 ID 对特定窗口进行捕获，保存为 JPEG 图片：
bash
magick import -window {{窗口id}} {{路径/到/输出图片.jpg}}

yt-dlp · 一个具有额外功能和修复的 youtube-dl 分支 ​

从 YouTube 和其他网站下载视频。 另请参阅：ytfzf。 更多信息：https://github.com/yt-dlp/yt-dlp#usage-and-options。

  • 下载视频或播放列表（使用下面命令的默认选项）：
bash
yt-dlp "{{https://www.youtube.com/watch?v=oHg5SJYRHA0}}"
  • 列出可下载的视频格式：
bash
yt-dlp {{[-F|--list-formats]}} "{{https://www.youtube.com/watch?v=oHg5SJYRHA0}}"
  • 使用最佳 MP4 视频格式下载视频或播放列表（默认为 "bv*+ba/b"）：
bash
yt-dlp {{[-f|--format]}} "{{bv*[ext=mp4]+ba[ext=m4a]/b[ext=mp4]}}" "{{https://www.youtube.com/watch?v=oHg5SJYRHA0}}"
  • 从视频中提取音频（需要 ffmpeg 或 ffprobe）：
bash
yt-dlp {{[-x|--extract-audio]}} "{{https://www.youtube.com/watch?v=oHg5SJYRHA0}}"
  • 指定提取音频的格式和音质（0（最佳）到 10（最差），默认值为 5）：
bash
yt-dlp {{[-x|--extract-audio]}} --audio-format {{mp3}} --audio-quality {{0}} "{{https://www.youtube.com/watch?v=oHg5SJYRHA0}}"
  • 仅下载播放列表中的第二、第四、第五、第六和最后一项（第一项为 1，而非 0）：
bash
yt-dlp {{[-I|--playlist-items]}} 2,4:6,-1 "{{https://youtube.com/playlist?list=PLbzoR-pLrL6pTJfLQ3UwtB-3V4fimdqnA}}"
  • 下载 YouTube 频道/用户的所有播放列表，并将每个播放列表保存在单独的目录中：
bash
yt-dlp {{[-o|--output]}} "{{%(uploader)s/%(playlist)s/%(playlist_index)s - %(title)s.%(ext)s}}" "{{https://www.youtube.com/user/TheLinuxFoundation/playlists}}"
  • 下载 Udemy 课程，并将每章保存在单独的目录中：
bash
yt-dlp {{[-u|--username]}} {{用户}} {{[-p|--password]}} {{密码}} {{[-P|--paths]}} "{{路径/到/目录}}" {{[-o|--output]}} "{{%(playlist)s/%(chapter_number)s - %(chapter)s/%(title)s.%(ext)s}}" "{{https://www.udemy.com/java-tutorial}}"

youtube-dl · 从 YouTube 和其他网站下载视频 ​

另请参阅：yt-dlp, ytfzf, you-get。 更多信息：https://rg3.github.io/youtube-dl/。

  • 下载一个视频或播放列表：
bash
youtube-dl '{{https://www.youtube.com/watch?v=oHg5SJYRHA0}}'
  • 列出视频或播放列表的所有可用格式：
bash
youtube-dl {{[-F|--list-formats]}} '{{https://www.youtube.com/watch?v=Mwa0_nE9H7A}}'
  • 以特定质量下载视频或播放列表：
bash
youtube-dl {{[-f|--format]}} "{{best[height<=480]}}" '{{https://www.youtube.com/watch?v=oHg5SJYRHA0}}'
  • 下载视频的音频并将其转换为 MP3：
bash
youtube-dl {{[-x|--extract-audio]}} --audio-format {{mp3}} '{{url}}'
  • 下载最佳质量的音频和视频并合并它们：
bash
youtube-dl {{[-f|--format]}} bestvideo+bestaudio '{{url}}'
  • 将视频下载为 MP4 文件并自定义文件名：
bash
youtube-dl {{[-f|--format]}} {{mp4}} {{[-o|--output]}} "{{%(playlist_index)s-%(title)s by %(uploader)s on %(upload_date)s in %(playlist)s.%(ext)s}}" '{{url}}'
  • 下载特定语言的字幕并与视频一起保存：
bash
youtube-dl --sub-lang {{en}} --write-sub '{{https://www.youtube.com/watch?v=Mwa0_nE9H7A}}'
  • 下载一个播放列表并从中提取 MP3：
bash
youtube-dl {{[-f|--format]}} "bestaudio" {{[-c|--continue]}} {{[-w|--no-overwrites]}} {{[-i|--ignore-errors]}} {{[-x|--extract-audio]}} --audio-format mp3 {{[-o|--output]}} "%(title)s.%(ext)s" '{{url_to_playlist}}'

you-get · 从网络下载媒体内容（视频、音频、图像） ​

另请参阅：yt-dlp, youtube-viewer, instaloader。 更多信息：https://you-get.org/#getting-started。

  • 打印网络上指定媒体的媒体信息：
bash
you-get {{[-i|--info]}} {{https://example.com/video?id=value}}
  • 从指定 URL 下载媒体：
bash
you-get {{https://example.com/video?id=value}}
  • 在 Google 视频上搜索并下载：
bash
you-get {{关键词}}
  • 将媒体下载到指定位置：
bash
you-get {{[-o|--output-dir]}} {{路径/到/目录}} {{[-O|--output-filename]}} {{文件名}} {{https://example.com/watch?v=value}}
  • 使用代理下载媒体：
bash
you-get {{[-x|--http-proxy]}} {{代理服务器}} {{https://example.com/watch?v=value}}

ytmdl · 从 YouTube 下载歌曲并自动添加元数据 ​

从 iTunes、Spotify 等来源获取歌曲信息（艺术家、专辑、封面等）。 更多信息：https://github.com/deepjyoti30/ytmdl#usage。

  • 通过歌曲名称下载（交互式选择）：
bash
ytmdl {{歌曲名称}}
  • 不提示直接下载第一个结果：
bash
ytmdl {{[-q|--quiet]}} {{歌曲名称}}
  • 将歌曲下载到指定目录：
bash
ytmdl {{[-o|--output-dir]}} {{路径/到/目录}} {{歌曲名称}}
  • 从 YouTube URL 下载歌曲：
bash
ytmdl --url https://www.youtube.com/watch?v={{oHg5SJYRHA0}}
  • 以指定格式（mp3、m4a 或 opus）下载歌曲：
bash
ytmdl --format {{mp3|m4a|opus}} {{歌曲名称}}
  • 下载歌曲并指定艺术家和专辑信息：
bash
ytmdl --artist {{艺术家名称}} --album {{专辑名称}} {{歌曲名称}}
  • 从文本文件中批量下载歌曲列表：
bash
ytmdl --list {{路径/到/歌曲列表.txt}}
  • 显示帮助：
bash
ytmdl {{[-h|--help]}}
