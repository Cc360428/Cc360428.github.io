编辑代码、使用编程助手与交互计算 ​

编辑器与编程助手在前，Julia/Jupyter 交互计算在后；数据库交互用 usql。

code · 跨平台且可扩展的代码编辑器 ​

更多信息：https://code.visualstudio.com/docs/configure/command-line。

  • 启动 Visual Studio Code：
bash
code
  • 打开指定的文件或目录：
bash
code {{路径/到/文件或目录1 路径/到/文件或目录2 ...}}
  • 比较两个指定的文件：
bash
code {{[-d|--diff]}} {{路径/到/文件1}} {{路径/到/文件2}}
  • 在新窗口中打开指定的文件或目录：
bash
code {{[-n|--new-window]}} {{路径/到/文件或目录1 路径/到/文件或目录2 ...}}
  • 安装/卸载一个特定的插件：
bash
code --{{install|uninstall}}-extension {{插件作者.插件名}}
  • 输出已安装的插件：
bash
code --list-extensions
  • 输出已安装的插件及其版本：
bash
code --list-extensions --show-versions
  • 以超级用户（root）身份启动编辑器，同时将用户数据存储在指定目录中：
bash
sudo code --user-data-dir {{路径/到/目录}}

qtcreator · 跨平台的 Qt 应用程序集成开发环境 ​

更多信息：https://doc.qt.io/qtcreator/creator-cli.html。

  • 启动 Qt Creator：
bash
qtcreator
  • 启动 Qt Creator 并恢复上次会话：
bash
qtcreator -lastsession
  • 启动 Qt Creator 并且不加载指定的插件：
bash
qtcreator -noload {{指定插件}}
  • 启动 Qt Creator 并且不加载任何插件：
bash
qtcreator -noload {{all}}
  • 在演示模式下启动 Qt Creator，并显示键盘快捷键的弹出提示：
bash
qtcreator -presentationMode
  • 启动 Qt Creator 并显示来自特定提交的差异：
bash
qtcreator -git-show {{提交}}

agy · Google 的代理式开发平台 ​

更多信息：https://antigravity.google/docs。

  • 打开特定文件或目录：
bash
agy {{路径/到/文件或目录}}
  • 比较两个文件：
bash
agy {{[-d|--diff]}} {{路径/到/文件1}} {{路径/到/文件2}}
  • 传入提示词来运行一个在当前工作目录的聊天会话：
bash
agy chat "{{提示词}}"
  • 安装或卸载特定扩展：
bash
agy --{{install|uninstall}}-extension {{发布者.扩展|路径/到/扩展.vsix}}
  • 向用户配置文件添加 MCP（Model Context Protocol）服务器定义：
bash
agy --add-mcp "{{json_字符串}}"
  • 显示帮助：
bash
agy {{[-h|--help]}}

codex · 由 OpenAI 驱动的终端自然语言代码助手 ​

读取并编辑当前目录中的文件以完成请求。 更多信息：https://developers.openai.com/codex/cli/reference。

  • 在当前目录中启动交互式 Codex 会话：
bash
codex
  • 使用提示词运行单个 Codex 命令：
bash
codex "{{提示词}}"
  • 运行提示词，允许 Codex 编辑工作区中的文件：
bash
codex --sandbox workspace-write "{{提示词}}"
  • 使用特定模型：
bash
codex {{[-m|--model]}} {{模型名称}} "{{提示词}}"
  • 使用本地开源模型提供商：
bash
codex --oss --local-provider {{lmstudio|ollama}} "{{提示词}}"
  • [交互式] 显示会话配置和词元使用情况：
bash
/status
  • 显示帮助：
bash
codex {{[-h|--help]}}

qwen · 使用 Qwen3-Coder 启动一个交互式提示 ​

另请参阅：gemini。 更多信息：https://github.com/QwenLM/qwen-code。

  • 启动一个 REPL 会话以进行交互式对话：
bash
qwen
  • 将另一个命令的输出发送给 Qwen 并立即退出：
bash
{{echo "总结罗马的历史"}} | qwen {{[-p|--prompt]}}
  • 覆盖默认模型（默认值：qwen3-coder-max）：
bash
qwen {{[-m|--model]}} {{model_name}}
  • 在沙盒容器中运行：
bash
qwen {{[-s|--sandbox]}}
  • 执行一个提示，然后保持在交互模式中：
bash
qwen {{[-i|--prompt-interactive]}} "{{给我一个 Python 中递归的示例}}"
  • 在上下文中包含所有文件：
bash
qwen {{[-a|--all-files]}}
  • 在状态栏中显示内存使用情况：
bash
qwen --show-memory-usage

julia · 一种用于技术计算的高层次、高性能动态编程语言 ​

更多信息：https://docs.julialang.org/en/v1/manual/getting-started/。

  • 启动一个 REPL（交互式 shell）：
bash
julia
  • 执行一个 Julia 程序并退出：
bash
julia {{program.jl}}
  • 执行一个带有参数的 Julia 程序：
bash
julia {{program.jl}} {{参数}}
  • 执行包含 Julia 代码的字符串：
bash
julia {{[-e|--eval]}} '{{julia_代码}}'
  • 执行一段 Julia 代码，并向其传递参数：
bash
julia {{[-e|--eval]}} '{{for x in ARGS; println(x); end}}' {{参数}}
  • 计算一个表达式并打印结果：
bash
julia {{[-E|--print]}} '{{(1 - cos(pi/4))/2}}'
  • 以多线程模式启动 Julia，使用 N 个线程：
bash
julia {{[-t|--threads]}} {{N}}

jupyter · 用于创建和共享包含代码、可视化和笔记的文档的 Web 应用程序 ​

主要用于数据分析、科学计算和机器学习。 更多信息：https://docs.jupyter.org/en/latest/use/jupyter-command.html。

  • 在当前目录下启动一个 Jupyter notebook 服务器：
bash
jupyter notebook
  • 打开一个特定的 Jupyter notebook：
bash
jupyter notebook {{示例}}.ipynb
  • 将特定 Jupyter notebook 导出为其他格式：
bash
jupyter nbconvert --to {{html|markdown|pdf|script}} {{示例}}.ipynb
  • 在指定端口启动服务器：
bash
jupyter notebook --port {{端口}}
  • 列出当前正在运行的 notebook 服务器：
bash
jupyter notebook list
  • 停止当前正在运行的服务器：
bash
jupyter notebook stop
  • 启动 JupyterLab（如果已安装）于当前目录：

参见 jupyter lab。

jupyter lab · Jupyter 笔记本的交互式开发环境 ​

更多信息：https://jupyterlab.readthedocs.io/en/stable/getting_started/starting.html。

  • 启动 JupyterLab：
bash
jupyter lab
  • 打开一个特定的笔记本：
bash
jupyter lab {{路径/到/笔记本}}.ipynb
  • 在特定目录中启动 JupyterLab：
bash
jupyter lab --notebook-dir {{路径/到/目录}}
  • 在调试模式下启动 JupyterLab：
bash
jupyter lab --debug

usql · 通用 SQL 数据库的命令行界面 ​

更多信息：https://github.com/xo/usql#using。

  • 连接到一个特定的数据库：
bash
usql {{sqlserver|mysql|postgres|sqlite3|...}}://{{用户名}}:{{密码}}@{{主机}}:{{端口}}/{{数据库名}}
  • 从文件中执行命令：
bash
usql --file={{路径/到/文件.sql}}
  • 执行一个特定的 SQL 命令：
bash
usql --command="{{sql命令}}"
  • 在 usql 提示符下运行一个 SQL 命令：
bash
{{prompt}}=> {{sql命令}}
  • 显示数据库架构：
bash
{{prompt}}=> \d
  • 将查询结果导出到一个特定文件：
bash
{{prompt}}=> \g {{路径/到/结果文件}}
  • 从 CSV 文件导入数据到一个特定表：
bash
{{prompt}}=> \copy {{路径/到/data.csv}} {{表名}}

tldr · 显示来自 tldr-pages 项目的命令行工具的简单帮助页面 ​

注意：--language 和 --list 选项并非客户端规范所必需，但大多数客户端都实现了它们。 更多信息：https://github.com/tldr-pages/tldr/blob/main/CLIENT-SPECIFICATION.md#command-line-interface。

  • 打印指定命令的 tldr 页面（提示：这就是你来到这里的方式！）：
bash
tldr {{命令}}
  • 打印指定子命令的 tldr 页面：
bash
tldr {{命令}} {{子命令}}
  • 用指定语言打印命令的 tldr 页面（如果没有，返回英语）：
bash
tldr {{[-L|--language]}} {{语言代码}} {{命令}}
  • 打印指定平台的命令的 tldr 页面：
bash
tldr {{[-p|--platform]}} {{android|common|freebsd|linux|osx|netbsd|openbsd|sunos|windows}} {{命令}}
  • 更新 tldr 页面的本地缓存：
bash
tldr {{[-u|--update]}}
  • 列出当前平台和 common 的所有页面：
bash
tldr {{[-l|--list]}}
  • 在终端窗口中浏览 tldr 页面（需要有 fzf）：
bash
tldr {{[-l|--list]}} | fzf --preview "tldr {1} --color=always" --preview-window=right,70% | xargs tldr
  • 打印随机命令的 tldr 页面：
bash
tldr {{[-l|--list]}} | shuf {{[-n|--head-count]}} 1 | xargs tldr
